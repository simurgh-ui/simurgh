# @simurgh-ui/preact

The Preact adapter exposes the complete Simurgh component catalog through Preact-native JSX and
`preact/compat`. It shares the React adapter's public symbol contract while carrying targeted
event fixes for native Preact behavior.

```tsx
import { Button } from '@simurgh-ui/preact/button';
```

The package includes per-component entry points, charts, SSR-safe overlays, and source-copy support
through `@simurgh-ui/cli`.

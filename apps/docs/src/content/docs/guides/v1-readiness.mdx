This scorecard is the public view of Simurgh's progress toward a stable `1.0.0`. A dimension is
**ready** only when its automated gates pass and its required human evidence is recorded. **In
progress** means useful evidence exists but at least one published exit criterion remains open.
**Blocked** means the release cannot advance until the named prerequisite is completed.

Last assessed: **2026-08-20**. Overall status: **in progress**.

## Scorecard

## Update policy

Review the scorecard in every release-candidate pull request and whenever a linked gate changes.
Status promotions require a repository link, CI run, or recorded human observation that satisfies
the remaining criterion. Regressions move a dimension back immediately; they are not deferred to
the next release review.

Before declaring `1.0.0`, every row must be **ready**, all P0 and P1 roadmap work must be closed or
explicitly deferred with rationale, a beta must be published, and beta feedback must be reviewed.
The repository [`todo.md`](https://github.com/simurgh-ui/simurgh/blob/main/todo.md) remains the
detailed work queue; this page is the concise release decision record.

## Current V1 blockers

The beta publication requirement is complete. The remaining evidence cannot be inferred from
automated tests: it requires consented first-time-user icon and release-candidate sessions, physical
Android TalkBack and iOS VoiceOver observations, the five documented manual accessibility checks,
and review of any issues those sessions discover. Stable versioning remains blocked until those
records pass their repository validators. CI publication also needs repaired npm credentials before
the first stable release so npm can attach build provenance.

---
title: Installation
---

Run the initializer inside an Angular, React, or Vue application:

```sh
pnpm dlx simurgh init
pnpm dlx simurgh add dialog tabs checkbox
```

`init` detects the framework, writes `simurgh.json`, copies tokens and recipes, and installs the core and positioning dependencies. `add` writes one framework-native source file per component and preserves existing files unless `--overwrite` is supplied. Use `simurgh diff dialog` before adopting registry updates.

Import `tokens.css` for semantic variables and `recipes.css` for the optional visual layer. Headless behavior does not depend on either stylesheet.

## Production imports

Prefer component subpaths so application bundlers receive the narrowest possible graph:

```tsx
import { Button } from '@simurgh-ui/react/button';
import '@simurgh-ui/styles/button.css';
```

The same pattern applies to Vue (`@simurgh-ui/vue/button`) and Angular (`@simurgh-ui/angular/button`). When several primitives are needed together, `@simurgh-ui/{framework}/basic` provides common non-floating controls, while `@simurgh-ui/{framework}/overlays` provides dialogs, menus, tooltips, and related positioned UI. The `basic` boundary intentionally excludes Floating UI.

Root adapter imports and `@simurgh-ui/styles/all.css` remain convenient opt-in aggregates. Use them when the complete catalog is genuinely required; component JavaScript and CSS subpaths are the recommended production default.

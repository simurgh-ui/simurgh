## استفاده

```tsx
<Command
  options={commands}
  placeholder="جست‌وجوی فرمان‌ها"
  noResults="فرمانی پیدا نشد"
  value={selectedCommand}
  onValueChange={runCommand}
/>
```

```vue
<Command
  :options="commands"
  placeholder="جست‌وجوی فرمان‌ها"
  v-model="selectedCommand"
/>
```

```html
<simurgh-command
  [options]="commands"
  placeholder="جست‌وجوی فرمان‌ها"
  [value]="selectedCommand"
  (valueChange)="runCommand($event)"
/>
```

## رفتار

input فهرست را فیلتر می‌کند، Arrow Up/Down میان itemهای فعال حرکت می‌کند، Home/End ابتدا و انتها را می‌گیرد و Enter action را انتخاب می‌کند. item disabled باید از navigation و activation کنار گذاشته شود.

برای search سمت server درخواست قبلی را هنگام تغییر query لغو کنید، loading را جداگانه نمایش دهید و آخرین نتیجهٔ موفق را تا رسیدن پاسخ تازه پایدار نگه دارید. پیام `noResults` نباید loading و نتیجهٔ خالی را با هم اشتباه بگیرد.

## دسترس‌پذیری

placeholder جای label نیست؛ Command به accessible name نیاز دارد. action انتخاب‌شده باید از طریق callback، `v-model` یا `valueChange` دقیقاً یک بار اجرا شود.

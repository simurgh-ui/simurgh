اگر loading از متن اطراف قابل‌فهم است Skeleton را تزئینی نگه دارید؛ اگر ناحیه مستقل است label کوتاه بدهید. ابعاد placeholder باید layout نهایی را تقریب بزند. shimmer با reduced motion متوقف شود و بارگذاری پایان‌یافته status تازه را بی‌دلیل تکرار نکند.

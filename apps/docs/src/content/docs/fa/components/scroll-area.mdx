## استفاده

```tsx
<ScrollArea label="فعالیت‌ها" orientation="vertical">
  {events}
</ScrollArea>
```

scroll بومی wheel، touch و صفحه‌کلید را حفظ می‌کند. فقط وقتی ناحیه مستقل و مهم است `label` و landmark اضافه کنید. focus نباید داخل ناحیه گیر کند و scrollbar سفارشی باید در forced colors و touch قابل‌استفاده بماند.

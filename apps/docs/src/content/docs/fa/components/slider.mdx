## استفاده

<Tabs>
<TabItem label="React">
```tsx
<Slider aria-label="بلندی صدا" name="volume" defaultValue={40} min={0} max={100} step={10} />
```
</TabItem>
<TabItem label="Vue">
```vue
<Slider v-model="volume" aria-label="بلندی صدا" name="volume" :step="10" />
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-slider [(value)]="volume" label="بلندی صدا" name="volume" [step]="10" />
```
</TabItem>
</Tabs>

همیشه با label دیداری یا `aria-label` نام دسترس‌پذیر فراهم کنید. ورودی بازهٔ بومی به‌طور خودکار کلیدهای جهت، Home، End، اشاره‌گر و لمس را پشتیبانی می‌کند. در حالت کنترل‌شده، برنامه باید هر تغییر را در مقدار منبع بازتاب دهد؛ مقدار پیش‌فرض فقط هنگام mount خوانده می‌شود.

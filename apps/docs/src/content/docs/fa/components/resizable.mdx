## استفاده

```tsx
<ResizablePanelGroup aria-label="پنل‌های فضای کار">
  <ResizablePanel defaultSize={35} minSize={20}>پیمایش</ResizablePanel>
  <ResizableHandle aria-label="تغییر اندازهٔ پنل‌ها" />
  <ResizablePanel defaultSize={65} minSize={30}>محتوا</ResizablePanel>
</ResizablePanelGroup>
```

Handle با Arrowها اندازه را تغییر می‌دهد و mapping افقی در RTL معکوس می‌شود. `minSize` و `maxSize` باید از ناپدیدشدن محتوا جلوگیری کنند. Handle به accessible name، focus indicator واضح و target pointer کافی نیاز دارد.

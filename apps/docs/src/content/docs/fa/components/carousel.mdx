## استفاده

```tsx
<Carousel label="پروژه‌های منتخب" direction="rtl">
  <CarouselContent>
    <CarouselItem>سیستم طراحی</CarouselItem>
    <CarouselItem>مستندات</CarouselItem>
  </CarouselContent>
  <CarouselPrevious>›</CarouselPrevious>
  <CarouselNext>‹</CarouselNext>
</Carousel>
```

## صفحه‌کلید

Tab viewport و کنترل‌ها را طبق DOM طی می‌کند. Arrow چپ و راست slide قبلی و بعدی را فعال می‌کنند و mapping آن‌ها در RTL معکوس می‌شود. Previous و Next باید accessible name روشن داشته باشند.

## دسترس‌پذیری

Carousel را با `label` نام‌گذاری کنید و جایگاه هر slide را قابل‌درک نگه دارید. پخش خودکار اگر اضافه می‌شود باید قابل توقف باشد و با reduced motion سازگار شود. محتوای خارج از slide فعال نباید focusهای گم‌شده ایجاد کند. `loop` را فقط وقتی فعال کنید که بازگشت از انتها به ابتدا برای کاربر قابل‌پیش‌بینی باشد.

## استفاده

```tsx
<Field>
  <FieldLegend>اعلان‌ها</FieldLegend>
  <FieldDescription id="channel-help">
    یک کانال انتخاب کنید.
  </FieldDescription>
  <Checkbox aria-describedby="channel-help">رایانامه</Checkbox>
  {error && <FieldError id="channel-error">{error}</FieldError>}
</Field>
```

## semantics

Field برای گروهی از کنترل‌های مرتبط است و ساختار `<fieldset>` و `<legend>` را حفظ می‌کند. برای یک Input منفرد از Label متصل استفاده کنید. Description و Error باید با ID پایدار و `aria-describedby` به کنترل مربوط وصل شوند.

Error فقط با رنگ مشخص نشود و هنگام submit نامعتبر در summary فرم نیز قابل‌یافتن باشد. کنترل disabled همچنان به legend گروه نیاز دارد، اما در submit بومی شرکت نمی‌کند.

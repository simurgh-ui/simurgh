## رفتار و API

اگر `src` بارگذاری شود تصویر نمایش داده می‌شود و در غیر این صورت fallback قطعی باقی می‌ماند.

| Prop/Input | Type | الزام |
| --- | --- | --- |
| `src` | `string` | اختیاری |
| `alt` | `string` | نام یا توضیح مناسب |
| `fallback` | متن یا `ReactNode` | لازم |

## دسترس‌پذیری

اگر نام شخص کنار Avatar نوشته شده و تصویر اطلاعات تازه‌ای ندارد، `alt=""` مناسب است. در غیر این صورت نام مختصر هویت را بنویسید. fallback نباید تنها وسیلهٔ انتقال هویت مهم باشد و رنگ نیز به‌تنهایی کافی نیست.

## معنا و دسترس‌پذیری

Meter مقدار فعلی را در یک بازهٔ معلوم نشان می‌دهد؛ برای پیشرفت task از Progress استفاده کنید. `min`، `max`، `low`، `high` و `optimum` باید ترتیب منطقی داشته باشند و label نوع اندازه‌گیری را روشن کند.

مقدار عددی یا متن معادل را کنار نمودار نگه دارید و وضعیت خوب/بد را فقط با رنگ نشان ندهید. Meter بومی semantics و announcement مناسب را در browser حفظ می‌کند.

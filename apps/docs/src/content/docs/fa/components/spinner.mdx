Spinner کار نامعین کوتاه را به‌صورت status زنده و نام‌دار اعلام می‌کند و نشانگر دیداری آن از فناوری کمکی پنهان است. اگر میزان پیشرفت قابل‌اندازه‌گیری است از Progress و برای نمایش شکل تقریبی محتوای آینده از Skeleton استفاده کنید.

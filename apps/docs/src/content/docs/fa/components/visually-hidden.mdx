## استفاده

<Tabs>
<TabItem label="React">
```tsx
<button>
  <CloseIcon aria-hidden />
  <VisuallyHidden>بستن dialog</VisuallyHidden>
</button>
```
</TabItem>
<TabItem label="Vue">
```vue
<button>
  <CloseIcon aria-hidden="true" />
  <VisuallyHidden>بستن dialog</VisuallyHidden>
</button>
```
</TabItem>
<TabItem label="Angular">
```html
<button>
  <simurgh-close-icon aria-hidden="true" />
  <simurgh-visually-hidden>بستن dialog</simurgh-visually-hidden>
</button>
```
</TabItem>
</Tabs>

Visually Hidden متن معنادار را بدون اشغال فضای دیداری در اختیار فناوری کمکی می‌گذارد؛ برای کنترل‌های فقط‌آیکن و راهنمای تکمیلی مفید است. کنترل تعاملی را با این primitive پنهان نکنید. متن پنهان باید کوتاه باشد و نام دسترس‌پذیر یا context ضروری اضافه کند.

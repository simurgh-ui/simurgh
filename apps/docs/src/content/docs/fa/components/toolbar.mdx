<Tabs>

</TabItem>

Toolbar کنترل‌های مرتبط را در یک توقف صفحه‌کلید گروه‌بندی می‌کند و هنگام جابه‌جایی focus موردهای غیرفعال را رد می‌کند. برای گروه عمودی `orientation="vertical"` را تعیین کنید. در حالت افقی راست‌به‌چپ، کلیدهای قبلی و بعدی مطابق جهت منطقی معکوس می‌شوند.

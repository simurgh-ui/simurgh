## استفاده

<Tabs>
<TabItem label="React">
```tsx
<TagsInput aria-label="مهارت‌ها" inputLabel="افزودن مهارت" name="skills" defaultValue={['TypeScript']} onValueChange={setSkills} />
```
</TabItem>
<TabItem label="Vue">
```vue
<TagsInput v-model="skills" aria-label="مهارت‌ها" input-label="افزودن مهارت" name="skills" />
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-tags-input aria-label="مهارت‌ها" inputLabel="افزودن مهارت" name="skills" [value]="skills" (valueChange)="skills = $event" />
```
</TabItem>
</Tabs>

Enter یا ویرگول مقدار جاری را اضافه می‌کند و Backspace روی ورودی خالی آخرین tag را حذف می‌کند. مقدار خالی و تکراری نادیده گرفته می‌شود. با تعیین `name`، برای هر tag یک ورودی پنهان ساخته می‌شود و `FormData.getAll(name)` فهرست کامل را برمی‌گرداند. label ورودی و دکمهٔ حذف را بومی‌سازی کنید.

## استفاده

```tsx
<Sheet>
  <SheetTrigger>بازکردن فیلترها</SheetTrigger>
  <SheetContent side="right">
    <SheetTitle>فیلترها</SheetTitle>
    <SheetDescription>نتایج قابل‌مشاهده را محدود کنید.</SheetDescription>
    <SheetClose>تمام</SheetClose>
  </SheetContent>
</Sheet>
```

Sheet modal است و focus را trap و پس از بستن به opener بازمی‌گرداند. Escape سطح بالایی را می‌بندد. `side` جهت فیزیکی panel است؛ اثر آن را در RTL بررسی کنید. title، description و close قابل‌مشاهده لازم‌اند.

## استفاده

<Tabs>
<TabItem label="React">
```tsx
<Table>
  <TableCaption>انتشارها</TableCaption>
  <TableHeader><TableRow><TableHead>نسخه</TableHead></TableRow></TableHeader>
  <TableBody><TableRow><TableCell>0.1.0</TableCell></TableRow></TableBody>
</Table>
```
</TabItem>
<TabItem label="Vue">
```vue
<Table>
  <TableCaption>انتشارها</TableCaption>
  <TableHeader><TableRow><TableHead>نسخه</TableHead></TableRow></TableHeader>
  <TableBody><TableRow><TableCell>0.1.0</TableCell></TableRow></TableBody>
</Table>
```
</TabItem>
<TabItem label="Angular">
```html
<table simurghTable>
  <caption simurghTableCaption>انتشارها</caption>
  <thead simurghTableHeader><tr simurghTableRow><th simurghTableHead>نسخه</th></tr></thead>
  <tbody simurghTableBody><tr simurghTableRow><td simurghTableCell>0.1.0</td></tr></tbody>
</table>
```
</TabItem>
</Tabs>

ساختار بومی caption، بخش‌ها، سطر، header و سلول را حفظ کنید. caption نام و هدف جدول را برای همه روشن می‌کند. در Angular از directiveهای ویژگی استفاده می‌شود تا ساختار معتبر عنصرهای بومی جدول تغییر نکند.

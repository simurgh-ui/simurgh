## semantics و امنیت

Link برای تغییر location است؛ برای action داخل صفحه از Button استفاده کنید. متن لینک باید بیرون از context نیز مقصد را روشن کند. `external` رفتار و نشانهٔ مقصد بیرونی را فعال می‌کند؛ هنگام بازکردن tab تازه، policy امن `rel` را حفظ کنید.

لینک disabled ذاتاً الگوی ضعیفی است. اگر مقصد موجود نیست لینک را render نکنید یا دلیل عدم دسترسی را توضیح دهید؛ عنصر بدون `href` نباید شبیه لینک فعال بماند.

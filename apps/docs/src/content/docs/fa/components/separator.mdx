Separator تزئینی از accessibility tree حذف می‌شود. اگر مرز ساختار معنایی مهمی را نشان می‌دهد `decorative` را خاموش و orientation درست را نگه دارید. فاصله یا heading اغلب از separatorهای زیاد خواناتر است.

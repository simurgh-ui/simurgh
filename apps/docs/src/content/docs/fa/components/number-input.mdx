## استفاده

```tsx
<NumberInput
  aria-label="تعداد"
  name="quantity"
  value={quantity}
  min={0}
  max={10}
  step={1}
  onValueChange={setQuantity}
/>
```

Vue از `v-model` و Angular از `[(value)]` استفاده می‌کنند. `min`، `max` و `step` باید با validation سمت server یکسان باشند.

کنترل‌های افزایش/کاهش accessible name روشن نیاز دارند. ورود مستقیم صفحه‌کلید، paste و مقدار خالی را پشتیبانی کنید و هنگام تجزیهٔ نامعتبر state خطا و متن اصلاح را نشان دهید.

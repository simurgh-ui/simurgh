## استفاده

<Tabs>
<TabItem label="React">
```tsx
<ToggleGroup aria-label="تراز متن">
  <ToggleGroupItem value="start">ابتدا</ToggleGroupItem>
  <ToggleGroupItem value="center">وسط</ToggleGroupItem>
</ToggleGroup>
```
</TabItem>
<TabItem label="Vue">
```vue
<ToggleGroup v-model="alignment" aria-label="تراز متن">
  <ToggleGroupItem value="start">ابتدا</ToggleGroupItem>
  <ToggleGroupItem value="center">وسط</ToggleGroupItem>
</ToggleGroup>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-toggle-group [(value)]="alignment" aria-label="تراز متن">
  <button simurghToggleGroupItem="start">ابتدا</button>
  <button simurghToggleGroupItem="center">وسط</button>
</simurgh-toggle-group>
```
</TabItem>
</Tabs>

برای فعال‌بودن هم‌زمان چند گزینه `type="multiple"` را تعیین کنید. هر item فقط‌آیکن باید نام دسترس‌پذیر داشته باشد. کلیدهای جهت focus را جابه‌جا می‌کنند، Home و End به ابتدا و انتها می‌روند و در layout راست‌به‌چپ جهت افقی به‌طور منطقی معکوس می‌شود.

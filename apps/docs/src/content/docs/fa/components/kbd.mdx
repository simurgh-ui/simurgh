## استفاده

```tsx
<p>
  برای جست‌وجو <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> را فشار دهید.
</p>
```

Angular از `<simurgh-kbd>` و Vue از `<Kbd>` استفاده می‌کند.

## دسترس‌پذیری

Kbd عنصر بومی `<kbd>` را حفظ می‌کند. نام کلید را مطابق platform و زبان رابط بنویسید و shortcut را تنها راه اجرای action قرار ندهید. برای ترکیب چند کلید، هر کلید را جدا و separator خوانا نمایش دهید.

Kbd تعاملی نیست؛ برای اجرای shortcut از Button یا کنترل واقعی استفاده کنید. shortcutهای سیستم‌عامل و assistive technology را override نکنید.

## استفاده

```tsx
<Badge tone="success">منتشرشده</Badge>
```

```vue
<Badge tone="warning">نیازمند بازبینی</Badge>
```

```html
<simurgh-badge tone="danger">ناموفق</simurgh-badge>
```

## API

| Prop/Input | Type | پیش‌فرض |
| --- | --- | --- |
| `tone` | `"neutral" \| "accent" \| "success" \| "warning" \| "danger"` | `"neutral"` |
| `status` | `boolean` | `false` |

وقتی `status` فعال باشد Badge با `role="status"` و live region مؤدبانه تغییر متن را اعلام می‌کند. برای metadata ثابت آن را خاموش نگه دارید.

## دسترس‌پذیری

متن Badge باید بدون وابستگی به رنگ قابل‌فهم باشد. برای عمل تعاملی از Button یا Link استفاده کنید؛ Badge به‌خودی‌خود کنترل نیست. تغییرات پرتکرار را live اعلام نکنید، چون می‌تواند صفحه‌خوان را شلوغ کند.

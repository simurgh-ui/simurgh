## استفاده

<Tabs>
<TabItem label="React">
```tsx
<Toggle defaultPressed onPressedChange={setBold}>ضخیم</Toggle>
```
</TabItem>
<TabItem label="Vue">
```vue
<Toggle v-model="bold">ضخیم</Toggle>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-toggle [(pressed)]="bold">ضخیم</simurgh-toggle>
```
</TabItem>
</Tabs>

Toggle یک انتخاب مستقل روشن یا خاموش را نمایش می‌دهد. رفتار صفحه‌کلید دکمهٔ بومی حفظ می‌شود و حالت از راه `aria-pressed` و `data-state` در دسترس است. در حالت کنترل‌شده، هر تغییر را در state برنامه ذخیره کنید. برای چند انتخاب مرتبط با جابه‌جایی focus از Toggle Group استفاده کنید.

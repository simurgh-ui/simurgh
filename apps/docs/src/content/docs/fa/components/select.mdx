## استفاده

```tsx
const cities = [
  { value: 'tehran', label: 'تهران' },
  { value: 'isfahan', label: 'اصفهان' },
];

<Select
  name="city"
  options={cities}
  value={city}
  onValueChange={setCity}
  placeholder="انتخاب شهر"
/>;
```

```vue
<Select
  v-model="city"
  name="city"
  :options="cities"
  placeholder="انتخاب شهر"
/>
```

```html
<simurgh-select
  name="city"
  [options]="cities"
  [(value)]="city"
  placeholder="انتخاب شهر"
/>
```

## صفحه‌کلید

Tab روی trigger قرار می‌گیرد. Arrow Down/Up فهرست را باز و option فعال را جابه‌جا می‌کند؛ Home/End ابتدا و انتها را انتخاب می‌کند؛ Enter یا Space انتخاب را ثبت و Escape فهرست را بدون تغییر focus می‌بندد.

## API و فرم

`options` آرایه‌ای از `SelectOption` و اجباری است. `value` و `onValueChange` در React، `v-model` در Vue و `[(value)]` در Angular state را کنترل می‌کنند. `defaultValue` حالت اولیه را در React ارائه می‌دهد. `name` و `required` در submit بومی شرکت می‌کنند.

برای جست‌وجوی متنی داخل گزینه‌ها از [Combobox](/fa/components/combobox/) استفاده کنید.

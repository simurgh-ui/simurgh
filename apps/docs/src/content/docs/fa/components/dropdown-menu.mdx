```sh
pnpm dlx @simurgh-ui/cli add dropdown-menu
```

```ts
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
} from '@simurgh-ui/react/dropdown-menu';
import '@simurgh-ui/styles/dropdown-menu.css';
```

Vue همین partها را صادر می‌کند. Angular از `DropdownMenuComponent` و `DropdownMenuItemDirective` استفاده می‌کند.

## استفاده

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>عملیات</DropdownMenuTrigger>
  <DropdownMenuContent aria-label="عملیات سند">
    <DropdownMenuItem onSelect={archive}>بایگانی</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

```html
<simurgh-dropdown-menu>
  <span trigger>عملیات</span>
  <button simurghMenuItem (select)="archive()">بایگانی</button>
</simurgh-dropdown-menu>
```

## صفحه‌کلید

Tab به trigger می‌رسد. Arrow بالا و پایین و Home/End میان itemهای فعال حرکت می‌کنند؛ Enter یا Space action را فعال می‌کند. Escape منو را می‌بندد و focus باید به trigger برگردد. item غیرفعال از navigation و activation کنار گذاشته می‌شود.

Content را با accessible name مشخص کنید. برای انتخاب state پایدار به‌جای action menu از Select یا Radio Group استفاده کنید.

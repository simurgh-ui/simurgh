## استفاده

```tsx
<Progress aria-label="بارگذاری فایل‌ها" value={68} />
```

با `value` مقدار مشخص و بدون آن حالت نامشخص نمایش داده می‌شود. برای اندازه‌گیری ثابت مانند فضای دیسک از Meter استفاده کنید. label باید task را نام ببرد و updateها بیش از حد اعلان نشوند. animation حالت نامشخص باید reduced motion را رعایت کند.

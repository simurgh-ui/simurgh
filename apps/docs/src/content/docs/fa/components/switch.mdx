## استفاده

```tsx
<Switch
  name="darkMode"
  value="enabled"
  checked={dark}
  onCheckedChange={setDark}
>
  حالت تیره
</Switch>
```

```vue
<Switch v-model="dark" name="darkMode" value="enabled">
  حالت تیره
</Switch>
```

```html
<simurgh-switch name="darkMode" value="enabled" [(checked)]="dark">
  حالت تیره
</simurgh-switch>
```

## زمان استفاده

Switch برای تنظیمی است که تغییر آن همان لحظه اعمال می‌شود. اگر کاربر چند گزینهٔ مستقل را انتخاب می‌کند یا تغییر فقط هنگام submit اعمال می‌شود، [Checkbox](/fa/components/checkbox/) مناسب‌تر است.

## state، فرم و دسترس‌پذیری

React از `checked`/`onCheckedChange` یا `defaultChecked`، Vue از `v-model` و Angular از `[(checked)]` استفاده می‌کنند. Space حالت را تغییر می‌دهد. label باید نتیجهٔ روشن و خاموش را قابل‌فهم کند و state تنها با رنگ نشان داده نشود.

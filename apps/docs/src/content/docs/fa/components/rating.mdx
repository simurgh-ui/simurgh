## استفاده

```tsx
<Rating
  aria-label="امتیاز محصول"
  name="rating"
  defaultValue={3}
  max={5}
  onValueChange={setRating}
/>
```

Vue از `v-model` و Angular از `[(value)]` استفاده می‌کنند. Arrowها میان امتیازها حرکت می‌کنند و مقدار انتخابی با `name` در فرم ثبت می‌شود. هر گزینه باید مقدار قابل‌خواندن مانند «۳ از ۵» داشته باشد و معنا فقط با شکل ستاره منتقل نشود.

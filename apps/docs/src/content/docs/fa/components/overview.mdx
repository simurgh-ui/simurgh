کامپوننت‌های Simurgh رفتار مشترک دسترس‌پذیری را با API بومی Angular، React و Vue ترکیب می‌کنند. هر صفحه نمونه‌ها، API و نکات دسترس‌پذیری همان کامپوننت را ارائه می‌دهد.

## ورودی و فرم

- [Button](/components/button/)، [Input](/components/input/) و [Textarea](/components/textarea/)
- [Checkbox](/components/checkbox/)، [Radio Group](/components/radio-group/) و [Switch](/components/switch/)
- [Select](/components/select/)، [Combobox](/components/combobox/) و [Date Picker](/components/date-picker/)
- [File Upload](/components/file-upload/)

## پیمایش و ساختار

- [Accordion](/components/accordion/) و [Tabs](/components/tabs/)
- [Breadcrumb](/components/breadcrumb/) و [Pagination](/components/pagination/)
- [Navigation Menu](/components/navigation-menu/) و [Sidebar](/components/sidebar/)

## لایه‌ها و بازخورد

- [Dialog](/components/dialog/)، [Alert Dialog](/components/alert-dialog/) و [Drawer](/components/drawer/)
- [Popover](/components/popover/) و [Tooltip](/components/tooltip/)
- [Toast](/components/toast/)، [Alert](/components/alert/) و [Progress](/components/progress/)

صفحات ترجمه‌نشده فعلاً با پیام fallback به انگلیسی نمایش داده می‌شوند؛ بنابراین همهٔ مستندات از نسخهٔ فارسی قابل‌دسترسی هستند و ترجمه می‌تواند به‌تدریج کامل شود.

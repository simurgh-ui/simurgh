## استفاده

```tsx
<Label htmlFor="email">نشانی رایانامه</Label>
<Input id="email" name="email" type="email" />
```

```vue
<Label for="email">نشانی رایانامه</Label>
<Input id="email" name="email" type="email" />
```

```html
<simurgh-label for="email">نشانی رایانامه</simurgh-label>
<simurgh-input id="email" name="email" type="email" />
```

## دسترس‌پذیری

`for`/`htmlFor` باید با ID یکتای کنترل برابر باشد. کلیک روی Label باید کنترل را focus یا toggle کند. placeholder جای Label نیست و متن Required باید علاوه بر نشانهٔ بصری برای صفحه‌خوان قابل‌درک باشد.

برای گروه Checkbox یا Radio Group از legend یا accessible group label استفاده کنید. Label نباید چند کنترل نامرتبط را هم‌زمان هدف بگیرد.

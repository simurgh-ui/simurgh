Tree دادهٔ سلسله‌مراتبی را به‌صورت یک توقف Tab نمایش می‌دهد؛ برای پیمایش سایت از آن استفاده نکنید. ریشه label کوتاه، هر شاخه نام‌های یکتا و گره‌های unavailable حالت disabled داشته باشند. جهت‌های بالا و پایین میان موردهای دیداری حرکت می‌کنند؛ Home و End به مرزها می‌روند و جهت‌های راست و چپ بازشدن، بسته‌شدن و حرکت میان والد و فرزند را کنترل می‌کنند.

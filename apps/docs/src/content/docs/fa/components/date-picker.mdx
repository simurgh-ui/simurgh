## استفاده

```tsx
<DatePicker
  value={date}
  onValueChange={setDate}
  name="appointment"
  min="2026-08-21"
  max="2026-09-30"
  disabledDates={holidays}
  label="تاریخ وقت ملاقات"
  locale="fa-IR"
  required
/>
```

```vue
<DatePicker
  v-model="date"
  v-model:month="month"
  name="appointment"
  label="تاریخ وقت ملاقات"
/>
```

```html
<simurgh-date-picker
  [(value)]="date"
  [(month)]="month"
  name="appointment"
  label="تاریخ وقت ملاقات"
/>
```

## مقدار و validation

نمایش می‌تواند با locale فارسی باشد، اما مقدار فرم با ISO یعنی `YYYY-MM-DD` باقی می‌ماند. `min`، `max` و `disabledDates` را در client و server یکسان نگه دارید و محدودیت را دوباره در server validate کنید.

## صفحه‌کلید

Tab trigger و grid باز را طی می‌کند. Arrowها روز را حرکت می‌دهند، Home/End به لبهٔ هفته می‌روند، Enter یا Space انتخاب می‌کند و Escape popover را می‌بندد. حرکت چپ و راست در RTL معکوس است و focus پس از بستن به trigger بازمی‌گردد.

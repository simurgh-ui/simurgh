```tsx

  label="بارگذاری مدارک"
  description="فقط فایل PDF"
  accept=".pdf"
  multiple
  name="documents"
  onFilesChange={setFiles}
/>
```

```html
<simurgh-file-upload
  label="بارگذاری مدارک"
  description="فقط فایل PDF"
  accept=".pdf"
  name="documents"
  [multiple]="true"
  (filesChange)="files = $event"
/>
```

## validation و دسترس‌پذیری

`accept` فقط راهنمای file picker است و جای validation سمت server را نمی‌گیرد. نوع، اندازه، تعداد و محتوای فایل را دوباره بررسی کنید. label و محدودیت‌ها باید پیش از انتخاب قابل‌مشاهده باشند و نتیجهٔ موفق یا خطا با live feedback کوتاه اعلام شود.

کشیدن و رهاکردن باید مکمل input بومی باشد؛ کاربر صفحه‌کلید باید بتواند همان فایل‌ها را انتخاب کند. نام فایل را نمایش دهید، اما مسیر محلی یا دادهٔ حساس را ذخیره نکنید.

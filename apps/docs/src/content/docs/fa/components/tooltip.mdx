## استفاده

<Tabs>
<TabItem label="React">
```tsx
<Tooltip>
  <TooltipTrigger aria-label="کپی نشانی">کپی</TooltipTrigger>
  <TooltipContent>کپی نشانی</TooltipContent>
</Tooltip>
```
</TabItem>
<TabItem label="Vue">
```vue
<Tooltip>
  <TooltipTrigger aria-label="کپی نشانی">کپی</TooltipTrigger>

```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-tooltip>
  <button trigger aria-label="کپی نشانی">کپی</button>
  <span>کپی نشانی</span>
</simurgh-tooltip>
```
</TabItem>
</Tabs>

Tooltip فقط برای توضیح تکمیلی کوتاه است و نباید کنترل تعاملی در خود داشته باشد. محتوا هم با hover و هم با focus ظاهر می‌شود و `role="tooltip"` دارد. برای اطلاعات ضروری یا تعاملی از محتوای درون‌صفحه‌ای یا Popover استفاده کنید.

## استفاده

<Tabs>
<TabItem label="React">
```tsx
const { toast } = useToast();
toast({ title: 'ذخیره شد', description: 'تغییرهای شما منتشر شدند.' });
// ToastViewport را داخل ToastProvider رندر کنید.
```
</TabItem>
<TabItem label="Vue">
```ts
const { toast } = useToast();
toast({ title: 'ذخیره شد', description: 'تغییرهای شما منتشر شدند.' });
// ToastViewport را داخل ToastProvider رندر کنید.
```
</TabItem>
<TabItem label="Angular">
```ts
@ViewChild(ToastViewportComponent) toasts!: ToastViewportComponent;
this.toasts.toast({ title: 'ذخیره شد', description: 'تغییرهای شما منتشر شدند.' });
```
</TabItem>
</Tabs>

فراهم‌کننده صف پیام‌ها را نگه می‌دارد و viewport آن‌ها را به‌صورت status مؤدبانه اعلام می‌کند. پیام را کوتاه نگه دارید و برای هر toast دکمهٔ بستن با نام روشن فراهم کنید. اگر کاربر باید پیش از ادامه پاسخ دهد، dialog یا خطای درون‌صفحه‌ای مناسب‌تر است.

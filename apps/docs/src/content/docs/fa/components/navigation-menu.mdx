
```ts
import {
  NavigationMenu,
  NavigationMenuList,
  NavigationMenuItem,
  NavigationMenuLink,
} from '@simurgh-ui/react/navigation-menu';
import '@simurgh-ui/styles/navigation-menu.css';
```

## استفاده

```tsx
<NavigationMenu label="پیمایش اصلی">
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuLink href="/" current>خانه</NavigationMenuLink>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuLink href="/fa/guides/installation/">مستندات</NavigationMenuLink>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

Linkها باید `href` واقعی داشته باشند و صفحهٔ جاری با `current`/`aria-current="page"` مشخص شود. نام landmark را با `label` تعیین کنید. برای commandهای application از Menubar و برای actionها از Button استفاده کنید.

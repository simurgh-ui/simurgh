## استفاده

```tsx
<Pagination label="صفحه‌های نتایج">
  <PaginationContent>
    <PaginationItem><PaginationLink href="?page=1">۱</PaginationLink></PaginationItem>
    <PaginationItem><PaginationLink href="?page=2" current>۲</PaginationLink></PaginationItem>
  </PaginationContent>
</Pagination>
```

Pagination یک ناحیهٔ پیمایش نام‌دار و list پیوندهاست. صفحهٔ جاری باید `aria-current="page"` داشته باشد. Previous/Next را با متن یا accessible name مشخص و در ابتدا/انتها واقعاً غیرفعال کنید. تغییر صفحه باید heading یا نقطهٔ شروع نتایج را برای focus قابل‌یافتن نگه دارد.

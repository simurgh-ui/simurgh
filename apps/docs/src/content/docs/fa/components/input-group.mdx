## استفاده

```tsx
<Label id="website-label" htmlFor="website">وب‌سایت</Label>
<InputGroup aria-labelledby="website-label">
  <InputGroupAddon decorative>
    <InputGroupText>https://</InputGroupText>
  </InputGroupAddon>
  <Input id="website" name="website" placeholder="example.com" />
</InputGroup>
```

## semantics

Input داخل گروه همچنان کنترل بومی و صاحب value، name و validation است. Addon تزئینی را با `decorative` از accessibility tree حذف کنید. اگر prefix یا suffix برای درک مقدار ضروری است آن را در accessible description کنترل نیز منعکس کنید.

Button داخل Input Group باید accessible name مستقل داشته باشد. ترتیب بصری prefix/suffix را با CSS منطقی و `dir` بسازید، نه با جابه‌جایی DOM در RTL.

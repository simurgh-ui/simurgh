بستهٔ `@simurgh-ui/icons` شامل **{iconNames.length} آیکن کاربردی** برای پیمایش، عمل، وضعیت، فایل و layout است. هر آیکن به‌صورت کامپوننت نام‌دار Angular، React و Vue، کامپوننت dynamic، دادهٔ مستقل از فریم‌ورک و فایل SVG در دسترس است.

## نصب

```sh
pnpm add @simurgh-ui/icons
```

peer همان entry point فریم‌ورک را نصب کنید. برنامهٔ React به Vue یا Angular نیاز ندارد.

## انتخاب import

| نیاز | Import | راهنما |
| --- | --- | --- |
| آیکن ثابت برنامه | `@simurgh-ui/icons/react`، `/vue` یا `/angular` | کامپوننت نام‌دار به bundler اجازهٔ حذف آیکن‌های بدون استفاده را می‌دهد |
| نام برگرفته از داده | `SimurghIcon` هر فریم‌ورک | یک `name` تایپ‌شده با قالب kebab-case بدهید |
| markup سمت server | `renderIconSvg` از `@simurgh-ui/icons` | رشتهٔ SVG برمی‌گرداند؛ فقط نام و option قابل‌اعتماد را استفاده کنید |
| renderer سفارشی | `icons`، `iconNames`، `iconGroups` یا `getIcon` | تعریف و metadata مستقل از فریم‌ورک |
| asset ثابت | `@simurgh-ui/icons/svg/<name>` | وقتی component import لازم یا ممکن نیست |

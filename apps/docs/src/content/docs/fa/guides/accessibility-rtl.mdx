Simurgh رفتارهای پایهٔ دسترس‌پذیری را فراهم می‌کند، اما نام‌گذاری، متن خطا و ترتیب محتوای برنامه همچنان مسئولیت شماست.

## نام و توضیح قابل‌دسترس

- هر کنترل باید برچسب قابل‌مشاهده یا نام قابل‌دسترسی روشن داشته باشد.
- پیام خطا را به فیلد مربوط متصل کنید و تنها به رنگ متکی نباشید.
- متن Button باید نتیجهٔ عمل را توضیح دهد؛ مانند «ذخیره تغییرات».
- برای آیکن تزئینی نام جداگانه تعریف نکنید. دکمهٔ فقط‌آیکن به `aria-label` نیاز دارد.

## صفحه‌کلید و focus

ترتیب DOM را با ترتیب بصری هماهنگ نگه دارید. حلقهٔ focus، Escape و بازگرداندن focus در Dialog و overlayهای Simurgh پیاده‌سازی شده‌اند؛ این رفتار را با دستکاری مستقیم `tabindex` مختل نکنید.

## فعال‌کردن فارسی و RTL

زبان و جهت را روی سند مشخص کنید:

```html
<html lang="fa" dir="rtl">
```

در CSS از ویژگی‌های منطقی استفاده کنید تا یک استایل در هر دو جهت کار کند:

```css
.item {
  margin-inline-start: 1rem;
  padding-inline: 0.75rem;
  border-inline-start: 2px solid currentColor;
}
```

از `left` و `right` فقط وقتی استفاده کنید که واقعاً جهت فیزیکی مهم است. آیکن‌های جهت‌دار مانند فلش بازگشت ممکن است در RTL نیاز به آینه‌شدن داشته باشند؛ آیکن‌های غیرجهتی مثل جست‌وجو، پخش و علامت تجاری نباید خودکار آینه شوند.

## آزمون

رابط را با صفحه‌کلید، بزرگ‌نمایی، حالت کنتراست بالا و یک صفحه‌خوان آزمایش کنید. سپس صفحه را با هر دو `dir="ltr"` و `dir="rtl"` بررسی کنید؛ مخصوصاً ترتیب focus، منوهای شناور، tooltipها و محتوای ترکیبی فارسی و کد.

Simurgh UI رفتارهای دسترس‌پذیری مشترک را با ساختار بومی هر فریم‌ورک ترکیب می‌کند.
دستورهای CSS اختیاری آن از رنگ‌های فیروزه‌ای، آبی ایرانی، لعاب لاجوردی، آجر اخرایی،
زعفران و انار الهام گرفته‌اند.

برای استفاده از سیمرغ دو مسیر دارید:

- با CLI سورس بومی فریم‌ورک را داخل برنامه خود کپی کنید، آن را تغییر دهید و مالک آن بمانید.
- بسته منتشرشده Angular، React یا Vue را مثل یک وابستگی معمولی نصب و به‌روزرسانی کنید.

در هر دو روش می‌توانید از دستورهای CSS آماده استفاده کنید یا لایه بصری خودتان را بسازید.
سیمرغ برای استایل‌دهی به Tailwind وابسته نیست.

برای راه‌اندازی پروژه، [راهنمای نصب](/fa/guides/installation/) را بخوانید.

title: Empty
description: Structured zero-state content with optional live-status announcements.

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Empty presents a clear explanation and next action when a collection or workspace has no content. Its static form stays out of the accessibility tree's live regions; enable status only when the empty state appears after an asynchronous update.

    </div>

</ComponentPreview>

Use a concise heading, explain why the state is empty, and provide one primary recovery or creation action. Set `status` only for content that changes dynamically; persistent page content should remain static.

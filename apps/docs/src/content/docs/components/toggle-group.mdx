title: Toggle Group
description: Single or multiple pressed-state controls with logical keyboard navigation.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Toggle Group coordinates related toggle buttons, selection state, and orientation-aware focus movement.

<ComponentPreview title="Toggle Group">
  <div
    role="group"
    aria-label="Alignment"
    aria-orientation="horizontal"
    data-slot="toggle-group"
  >
    <button aria-pressed="true" data-state="on" data-slot="toggle-group-item">
      Start
    </button>
    <button aria-pressed="false" data-state="off" data-slot="toggle-group-item">
      Center
    </button>
    <button aria-pressed="false" data-state="off" data-slot="toggle-group-item">
      End
    </button>
  </div>
</ComponentPreview>

<Tabs>
<TabItem label="React">
```tsx
<ToggleGroup aria-label="Alignment"><ToggleGroupItem value="start">Start</ToggleGroupItem><ToggleGroupItem value="center">Center</ToggleGroupItem></ToggleGroup>
```
</TabItem>
<TabItem label="Vue">
```vue
<ToggleGroup v-model="alignment" aria-label="Alignment"><ToggleGroupItem value="start">Start</ToggleGroupItem><ToggleGroupItem value="center">Center</ToggleGroupItem></ToggleGroup>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-toggle-group [(value)]="alignment" aria-label="Alignment"><button simurghToggleGroupItem="start">Start</button><button simurghToggleGroupItem="center">Center</button></simurgh-toggle-group>
```
</TabItem>
</Tabs>

Use `type="multiple"` when more than one option may be active. Every icon-only item needs an accessible name.

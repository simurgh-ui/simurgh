## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add toggle-group
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  ToggleGroup,
  ToggleGroupItem,
} from '@simurgh-ui/react/toggle-group';
import '@simurgh-ui/styles/toggle-group.css';
```

### Vue

```ts
import {
  ToggleGroup,
  ToggleGroupItem,
} from '@simurgh-ui/vue/toggle-group';
import '@simurgh-ui/styles/toggle-group.css';
```

### Angular

```ts
import {
  ToggleGroupComponent,
  ToggleGroupItemDirective,
} from '@simurgh-ui/angular/toggle-group';
import '@simurgh-ui/styles/toggle-group.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Toggle Group coordinates related toggle buttons, selection state, and orientation-aware focus movement.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## Basic usage

<ComponentPreview title="Toggle Group">
  <div
    role="group"
    aria-label="Alignment"
    aria-orientation="horizontal"
    data-slot="toggle-group"
  >
    <button aria-pressed="true" data-state="on" data-slot="toggle-group-item">
      Start
    </button>
    <button aria-pressed="false" data-state="off" data-slot="toggle-group-item">
      Center
    </button>
    <button aria-pressed="false" data-state="off" data-slot="toggle-group-item">
      End
    </button>
  </div>
</ComponentPreview>

## State model

Use `type="multiple"` when more than one option may be active. Every icon-only item needs an accessible name.

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Card provides stable styling hooks without imposing interactive semantics. Use native headings, links, and buttons inside its anatomy.

<ComponentPreview title="Card">
  <article data-slot="card" style="max-width: 26rem">
    <header data-slot="card-header">
      <h3 data-slot="card-title">The Conference of the Birds</h3>
      <p data-slot="card-description">A journey through seven valleys.</p>
    </header>
    <div data-slot="card-content">
      Discover a composable, framework-native component system.
    </div>
    <footer data-slot="card-footer">
      <button class="simurgh-trigger">Read more</button>
    </footer>
  </article>
</ComponentPreview>

Card is intentionally neutral. Add `article`, `region`, or accessible naming only when the content warrants those semantics.

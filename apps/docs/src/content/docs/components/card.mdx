## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add card
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from '@simurgh-ui/react/card';
import '@simurgh-ui/styles/card.css';
```

### Vue

```ts
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from '@simurgh-ui/vue/card';
import '@simurgh-ui/styles/card.css';
```

### Angular

```ts
import {
  CardComponent,
  CardHeaderComponent,
  CardTitleComponent,
  CardDescriptionComponent,
  CardContentComponent,
  CardFooterComponent,
} from '@simurgh-ui/angular/card';
import '@simurgh-ui/styles/card.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Card provides stable styling hooks without imposing interactive semantics. Use native headings, links, and buttons inside its anatomy.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## State model

Card is intentionally neutral. Add `article`, `region`, or accessible naming only when the content warrants those semantics.

## Customization

Load the optional component stylesheet for the default recipe, override semantic tokens for broad

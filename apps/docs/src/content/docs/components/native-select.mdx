---
title: Native Select
description: Platform-native option selection with form and validation semantics.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Native Select preserves the operating system's picker experience, including mobile full-screen or wheel interfaces. It supports native form serialization, required validation, disabled state, multiple selection, and accessible labels.

<ComponentPreview title="Native Select">
  <label for="native-select-preview">Timezone</label>
  <select id="native-select-preview" name="timezone" data-slot="native-select">
    <option value="utc">UTC</option>
    <option value="tehran">Tehran</option>
    <option value="tokyo">Tokyo</option>
  </select>
</ComponentPreview>

<Tabs>
<TabItem label="React">
```tsx
<Label htmlFor="timezone">Timezone</Label>
<NativeSelect id="timezone" name="timezone" defaultValue="utc" required>
  <option value="utc">UTC</option>
  <option value="tehran">Tehran</option>
</NativeSelect>
```
</TabItem>
<TabItem label="Vue">
```vue
<Label for="timezone">Timezone</Label>
<NativeSelect id="timezone" name="timezone" v-model="timezone" required>
  <option value="utc">UTC</option>
  <option value="tehran">Tehran</option>
</NativeSelect>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-label for="timezone">Timezone</simurgh-label>
<simurgh-native-select id="timezone" name="timezone" [value]="timezone" [required]="true" (valueChange)="timezone = $event">
  <option value="utc">UTC</option>
  <option value="tehran">Tehran</option>
</simurgh-native-select>
```
</TabItem>
</Tabs>

Prefer Native Select when platform behavior, mobile usability, and minimal JavaScript matter more than a fully customized popup. Use Select when the product requires custom option presentation.

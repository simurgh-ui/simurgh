## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add native-select
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { NativeSelect } from '@simurgh-ui/react/native-select';
import '@simurgh-ui/styles/native-select.css';
```

### Vue

```ts
import { NativeSelect } from '@simurgh-ui/vue/native-select';
import '@simurgh-ui/styles/native-select.css';
```

### Angular

```ts
import { NativeSelectComponent } from '@simurgh-ui/angular/native-select';
import '@simurgh-ui/styles/native-select.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Native Select preserves the operating system's picker experience, including mobile full-screen or wheel interfaces. It supports native form serialization, required validation, disabled state, multiple selection, and accessible labels.

## State model

Prefer Native Select when platform behavior, mobile usability, and minimal JavaScript matter more than a fully customized popup. Use Select when the product requires custom option presentation.

## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add context-menu
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  ContextMenu,
  ContextMenuTrigger,
  ContextMenuContent,
  ContextMenuItem,
} from '@simurgh-ui/react/context-menu';
import '@simurgh-ui/styles/context-menu.css';
```

### Vue

```ts
import {
  ContextMenu,
  ContextMenuTrigger,
  ContextMenuContent,
  ContextMenuItem,
} from '@simurgh-ui/vue/context-menu';
import '@simurgh-ui/styles/context-menu.css';
```

### Angular

```ts
import {
  ContextMenuComponent,
  ContextMenuItemDirective,
} from '@simurgh-ui/angular/context-menu';
import '@simurgh-ui/styles/context-menu.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
<!-- component-installation:end -->

Context Menu opens at the pointer on right-click and beside its trigger from Shift+F10 or the Menu key. Focus enters the first enabled item, arrow keys navigate, and Escape dismisses the menu.

<TabItem label="React">
```tsx
<ContextMenu>
  <ContextMenuTrigger>Canvas</ContextMenuTrigger>
  <ContextMenuContent aria-label="Canvas actions">
    <ContextMenuItem onSelect={copy}>Copy</ContextMenuItem>
    <ContextMenuItem onSelect={duplicate}>Duplicate</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```
</TabItem>
<TabItem label="Vue">
```vue
<ContextMenu>
  <ContextMenuTrigger>Canvas</ContextMenuTrigger>
  <ContextMenuContent aria-label="Canvas actions">
    <ContextMenuItem @select="copy">Copy</ContextMenuItem>
    <ContextMenuItem @select="duplicate">Duplicate</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-context-menu>
  <span trigger>Canvas</span>
  <button simurghContextMenuItem (select)="copy()">Copy</button>
  <button simurghContextMenuItem (select)="duplicate()">Duplicate</button>
</simurgh-context-menu>
```
</TabItem>
</Tabs>

Keep the same actions available through visible controls when they are essential to completing a task; context menus should be a shortcut, not the only path.

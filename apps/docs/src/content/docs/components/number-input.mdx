## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add number-input
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { NumberInput } from '@simurgh-ui/react/number-input';
import '@simurgh-ui/styles/number-input.css';
```

### Vue

```ts
import { NumberInput } from '@simurgh-ui/vue/number-input';
import '@simurgh-ui/styles/number-input.css';
```

### Angular

```ts
import { NumberInputComponent } from '@simurgh-ui/angular/number-input';
import '@simurgh-ui/styles/number-input.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Number Input keeps native spinbutton semantics while providing larger, explicitly named step controls. Values are clamped to the configured minimum and maximum.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## Basic usage

## State model

Use a visible label when possible. Set `step` to the smallest meaningful change, and provide both `min` and `max` when the value has a bounded domain.

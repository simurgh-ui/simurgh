## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add skeleton
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Skeleton } from '@simurgh-ui/react/skeleton';
import '@simurgh-ui/styles/skeleton.css';
```

### Vue

```ts
import { Skeleton } from '@simurgh-ui/vue/skeleton';
import '@simurgh-ui/styles/skeleton.css';
```

### Angular

```ts
import { SkeletonComponent } from '@simurgh-ui/angular/skeleton';
import '@simurgh-ui/styles/skeleton.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
<!-- component-installation:end -->

Skeleton is hidden from assistive technology by default. Add a `label` only when the placeholder itself represents a meaningful loading region; this exposes a named busy status.

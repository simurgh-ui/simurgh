Combobox keeps DOM focus on its text input while arrow keys move an active option through `aria-activedescendant`. Enter commits, Escape restores the selected label, disabled options are skipped, and the selected value participates in native form submission.

## Anatomy and behavior

The component renders an editable combobox input, a conditional listbox, options, and an optional hidden form input. Styling hooks use `.simurgh-combobox`, `.simurgh-content`, and `.simurgh-item`; filtering and keyboard behavior remain independent of Tailwind.

- `ArrowDown` and `ArrowUp` cycle through enabled filtered options.
- `Home` and `End` move to the first and last enabled result.
- `Enter` commits the active option without moving input focus.
- `Escape` closes the list and restores the committed label.

Use a visible `<label>` or an explicit accessible label in production. `name`, `required`, and `disabled` follow native form concepts.

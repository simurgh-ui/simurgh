## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add toggle
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Toggle } from '@simurgh-ui/react/toggle';
import '@simurgh-ui/styles/toggle.css';
```

### Vue

```ts
import { Toggle } from '@simurgh-ui/vue/toggle';
import '@simurgh-ui/styles/toggle.css';
```

### Angular

```ts
import { ToggleComponent } from '@simurgh-ui/angular/toggle';
import '@simurgh-ui/styles/toggle.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.

## Purpose

Toggle represents an option that can be switched on or off. It uses native button keyboard behavior and exposes state through `aria-pressed` and `data-state`.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;

## State model

Use Toggle for independent choices. When several choices are mutually exclusive or share roving focus, use a dedicated Toggle Group rather than manually coordinating individual toggles.

## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add button-group
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  ButtonGroup,
  ButtonGroupText,
  ButtonGroupSeparator,
} from '@simurgh-ui/react/button-group';
import '@simurgh-ui/styles/button-group.css';
```

### Vue

```ts
import {
  ButtonGroup,
  ButtonGroupText,
  ButtonGroupSeparator,
} from '@simurgh-ui/vue/button-group';
import '@simurgh-ui/styles/button-group.css';
```

### Angular

```ts
import {
  ButtonGroupComponent,
  ButtonGroupTextComponent,
  ButtonGroupSeparatorComponent,
} from '@simurgh-ui/angular/button-group';
import '@simurgh-ui/styles/button-group.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

Button Group visually joins related actions while exposing a single named group to assistive technology. Use the text and separator parts for compact labels or for dividing distinct action sets.

<ComponentPreview title="Button Group">
  <div
    role="group"
    aria-label="Text alignment"
    aria-orientation="horizontal"
    data-slot="button-group"
  >
    <button type="button">Left</button>
    <button type="button">Center</button>
    <button type="button">Right</button>
  </div>
</ComponentPreview>

Give every Button Group an accessible name with `aria-label` or `aria-labelledby`. Keep keyboard behavior native to the contained controls; use Toggle Group when the buttons represent persistent selected states.

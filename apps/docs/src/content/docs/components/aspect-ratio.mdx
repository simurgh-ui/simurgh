title: Aspect Ratio

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Aspect Ratio reserves predictable space for media and responsive previews. Invalid, zero, or negative ratios safely fall back to `1`.

<ComponentPreview title="Aspect Ratio">
  <div
    class="preview-panel"
    style="inline-size: min(100%, 24rem); aspect-ratio: 16 / 9; display: grid; place-items: center; background: linear-gradient(135deg, hsl(var(--simurgh-persian-blue)), hsl(var(--simurgh-firuzeh))); color: white"
  >
    <strong>16:9 media</strong>
  </div>
</ComponentPreview>

<Tabs>
<TabItem label="React">
```tsx
<AspectRatio ratio={16 / 9}><img src={cover} alt="Mount Damavand" /></AspectRatio>
```
</TabItem>
<TabItem label="Vue">
```vue
<AspectRatio :ratio="16 / 9"><img :src="cover" alt="Mount Damavand" /></AspectRatio>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-aspect-ratio [ratio]="16 / 9"><img [src]="cover" alt="Mount Damavand" /></simurgh-aspect-ratio>
```
</TabItem>
</Tabs>

The primitive controls only the container ratio. Size media children to fill the container and choose `object-fit` according to whether cropping is acceptable.

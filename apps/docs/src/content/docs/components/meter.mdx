## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add meter
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Meter } from '@simurgh-ui/react/meter';
import '@simurgh-ui/styles/meter.css';
```

### Vue

```ts
import { Meter } from '@simurgh-ui/vue/meter';
import '@simurgh-ui/styles/meter.css';
```

### Angular

```ts
import { MeterComponent } from '@simurgh-ui/angular/meter';
import '@simurgh-ui/styles/meter.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

Meter communicates a measurement within a known range, such as storage usage or signal quality. Use Progress for task completion.

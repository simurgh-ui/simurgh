Meter communicates a measurement within a known range, such as storage usage or signal quality. Use Progress for task completion.

      max="100"
      low="40"
      high="80"

      72%
    </meter>

</ComponentPreview>

Provide an accessible name and visible text describing the measurement. Threshold meaning depends on whether higher or lower values are desirable, expressed through `optimum`.

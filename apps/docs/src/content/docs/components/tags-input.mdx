title: Tags Input
description: Accessible keyboard entry for compact lists of form values.

Tags Input turns short text values into removable tokens while retaining native text entry and form submission. Press Enter or comma to add the current value, Backspace on an empty control to remove the last tag, or use each tag's labelled remove button.

Duplicate and blank values are ignored. `maxTags` defaults to 20 and is capped at 100 to keep rendering bounded. When `name` is provided, every tag produces a hidden input with that name, so `FormData.getAll(name)` returns the complete list. Use `required` when at least one tag must be supplied, and provide localized input and removal labels where needed.

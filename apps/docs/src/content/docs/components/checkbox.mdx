## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add checkbox
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Checkbox } from '@simurgh-ui/react/checkbox';
import '@simurgh-ui/styles/checkbox.css';
```

### Vue

```ts
import { Checkbox } from '@simurgh-ui/vue/checkbox';
import '@simurgh-ui/styles/checkbox.css';
```

### Angular

```ts
import { CheckboxComponent } from '@simurgh-ui/angular/checkbox';
import '@simurgh-ui/styles/checkbox.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Checkbox exposes `aria-checked`, keyboard activation, controlled and uncontrolled state, and an optional native form value. Always provide a visible or programmatic label.

Boolean props without explicit defaults use Vue's `false` default. Undeclared attributes follow

### `Checkbox`

Automatic fallthrough is disabled; `attrs` are manually forwarded to the rendered root.

| Prop | Type | Default / requirement |
| --- | --- | --- |

| `defaultChecked` | `boolean` | `false` |
| `name` | `string` | `undefined` |
| `value` | `string` | `'on'` |
| `required` | `boolean` | `false` |

| Event | Payload |

### Angular

Inputs and outputs use their public template names. Public methods are callable through a template

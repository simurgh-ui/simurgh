## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add alert
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Alert } from '@simurgh-ui/react/alert';
import '@simurgh-ui/styles/alert.css';
```

### Vue

```ts
import { Alert } from '@simurgh-ui/vue/alert';
import '@simurgh-ui/styles/alert.css';
```

### Angular

```ts
import { AlertComponent } from '@simurgh-ui/angular/alert';
import '@simurgh-ui/styles/alert.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Alert announces feedback using a polite status region by default. Urgent mode switches to assertive alert semantics for important failures that require immediate attention.

## State model

Reserve `urgent` for errors that must interrupt the current announcement. Render static page notices without live-region semantics until their content actually changes.

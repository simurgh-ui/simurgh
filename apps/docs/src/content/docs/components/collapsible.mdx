import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Collapsible connects a native button to content through `aria-expanded` and `aria-controls`.

<ComponentPreview title="Collapsible">
  <details>
    <summary class="simurgh-trigger">Project details</summary>
    <div class="simurgh-content">Three framework-native implementations.</div>
  </details>
</ComponentPreview>

<Tabs>

  </TabItem>
</Tabs>

Use Accordion when multiple related sections form a coordinated set. Use Collapsible for one independent disclosure.

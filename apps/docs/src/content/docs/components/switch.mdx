## Purpose

Switch shares Checkbox's state and form contract but uses `role="switch"`. Use it for settings that take effect immediately, not for selecting items in a submission workflow.

{/* component-status:start */}
### Default presentation: native

The component preserves a familiar native element and browser behavior. The optional recipe harmonizes its appearance without replacing the platform interaction model.

## State model

Controlled state remains the application’s source of truth and must be updated from every change
event. Uncontrolled state reads its default only when the component mounts. Do not pass both forms of
the same state at once.

| Framework | Exact state contract and reset behavior |
| --- | --- |
| React | Controlled: `checked` + `onCheckedChange`. Uncontrolled: `defaultChecked`. Reset controlled state by assigning the initial value; reset uncontrolled state by changing a React `key`. |
| Vue | Controlled: `v-model` (`modelValue` + `update:modelValue`). No uncontrolled prop is exposed. Reset the model ref to its initial value; reset uncontrolled state with a changed Vue `:key`. |
| Angular | Controlled two-way binding: `[(checked)]` (`checked` + `checkedChange`). Angular exposes no separate default input; initialize and reset the bound class field explicitly. |

**React**

```tsx
const initialChecked = false;
const [checked, setChecked] = useState(initialChecked);
const [resetKey, setResetKey] = useState(0);

<Switch checked={checked} onCheckedChange={setChecked}>…</Switch>
<button onClick={() => setChecked(initialChecked)}>Reset controlled</button>
<Switch key={resetKey} defaultChecked={initialChecked}>…</Switch>
<button onClick={() => setResetKey((key) => key + 1)}>Reset uncontrolled</button>
```

**Vue**

```vue
<script setup lang="ts">
import { ref } from 'vue';
const initial = '';
const state = ref(initial);
const resetKey = ref(0);
</script>

<Switch v-model="state">…</Switch>
<button @click="state = initial">Reset controlled</button>
```

**Angular**

```ts
initial = false;
checked = this.initial;
reset() { this.checked = this.initial; }
```

```html
<simurgh-switch [(checked)]="checked">…</simurgh-switch>
<button type="button" (click)="reset()">Reset</button>
```

### Form integration

Use `name="notifications"` to serialize `value` when checked; omitted when unchecked. The examples initialize the field, keep its
value application-owned, forward `disabled` and `required`, render an accessible error, and read
the browser submission payload. This component has no public `invalid` prop; announce validation errors next to the labeled control and use native validity where available.

#### React

```tsx
const initial = true;
const [checked, setChecked] = useState(initial);
const [errors, setErrors] = useState<Record<string, string>>({});

<form onSubmit={(event) => {
  event.preventDefault();
  const data = new FormData(event.currentTarget);
  // Submit data.get('notifications').
}}>
  <Switch name="notifications" checked={checked} onCheckedChange={setChecked}
    required disabled={isDisabled} />
  {errors.notifications && <p role="alert">{errors.notifications}</p>}
  <button type="submit">Submit</button>
</form>
```

#### Vue

```vue
<script setup lang="ts">
import { reactive, ref } from 'vue';
const initial = true;
const value = ref(initial);
const errors = reactive<Record<string, string>>({});
function submit(event: Event) {
  const data = new FormData(event.currentTarget as HTMLFormElement);
  // Submit data.get('notifications').
}
</script>

<form @submit.prevent="submit">
  <Switch v-model="value" name="notifications" required :disabled="isDisabled"></Switch>
  <p v-if="errors.notifications" role="alert">{{ errors.notifications }}</p>
  <button type="submit">Submit</button>
</form>
```

#### Angular

```ts
initial = true;
checked = this.initial;
errors: Record<string, string> = {};
submit(form: HTMLFormElement) {
  const data = new FormData(form);
  // Submit data.get('notifications').
}
```

```html
<form #form (submit)="submit(form); $event.preventDefault()">
  <simurgh-switch [(checked)]="checked" name="notifications" required [disabled]="isDisabled"></simurgh-switch>
  <p *ngIf="errors.notifications" role="alert">{{ errors.notifications }}</p>
  <button type="submit">Submit</button>
</form>
```

For Angular reactive or template-driven forms, bridge the documented `value`/`valueChange` pair
to your form control. The component does not implement `ControlValueAccessor`; update disabled and
validation state from the Angular form explicitly.

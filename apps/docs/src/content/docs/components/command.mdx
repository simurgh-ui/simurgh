## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add command
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Command } from '@simurgh-ui/react/command';
import '@simurgh-ui/styles/command.css';
```

### Vue

```ts
import { Command } from '@simurgh-ui/vue/command';
import '@simurgh-ui/styles/command.css';
```

### Angular

```ts
import { CommandComponent } from '@simurgh-ui/angular/command';
import '@simurgh-ui/styles/command.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Command packages the library's combobox interaction contract as a persistent command surface. Users can filter actions, move through enabled results with arrow, Home, and End keys, select with Enter, and dismiss a surrounding palette with Escape.

## State model

Use concise verb-first labels and mark unavailable actions as disabled instead of removing them when their presence explains product capability. Put Command inside Dialog for a modal command palette and provide a visible trigger with its keyboard shortcut.

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Command packages the library's combobox interaction contract as a persistent command surface. Users can filter actions, move through enabled results with arrow, Home, and End keys, select with Enter, and dismiss a surrounding palette with Escape.

<Tabs>
<TabItem label="React">
```tsx
<Command
  options={commands}

/>
```
</TabItem>
<TabItem label="Vue">

<Command
  :options="commands"

</TabItem>
<TabItem label="Angular">
```html
<simurgh-command
  [options]="commands"
  placeholder="Search commands"
  [value]="selectedCommand"
  (valueChange)="runCommand($event)"
/>
```
</TabItem>
</Tabs>

Use concise verb-first labels and mark unavailable actions as disabled instead of removing them when their presence explains product capability. Put Command inside Dialog for a modal command palette and provide a visible trigger with its keyboard shortcut.

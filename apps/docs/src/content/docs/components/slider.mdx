## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add slider
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Slider } from '@simurgh-ui/react/slider';
import '@simurgh-ui/styles/slider.css';
```

### Vue

```ts
import { Slider } from '@simurgh-ui/vue/slider';
import '@simurgh-ui/styles/slider.css';
```

### Angular

```ts
import { SliderComponent } from '@simurgh-ui/angular/slider';
import '@simurgh-ui/styles/slider.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

Slider preserves native keyboard, pointer, constraint, and form semantics while exposing framework-native value updates.

<Tabs>
<TabItem label="React">
```tsx
<Slider aria-label="Volume" name="volume" defaultValue={40} min={0} max={100} step={10} />
```
</TabItem>
<TabItem label="Vue">
```vue
<Slider v-model="volume" aria-label="Volume" name="volume" :step="10" />
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-slider [(value)]="volume" label="Volume" name="volume" [step]="10" />
```
</TabItem>
</Tabs>

Always provide an accessible name through a visible label or `aria-label`. Native range inputs automatically support arrow, Home, End, pointer, and touch interaction.

## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add radio-group
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  RadioGroup,
  RadioGroupItem,
} from '@simurgh-ui/react/radio-group';
import '@simurgh-ui/styles/radio-group.css';
```

### Vue

```ts
import {
  RadioGroup,
  RadioGroupItem,
} from '@simurgh-ui/vue/radio-group';
import '@simurgh-ui/styles/radio-group.css';
```

### Angular

```ts
import {
  RadioGroupComponent,
  RadioGroupItemDirective,
} from '@simurgh-ui/angular/radio-group';
import '@simurgh-ui/styles/radio-group.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

Radio Group allows one value from a visible set. Arrow keys move and select, Home/End jump to the boundaries, horizontal movement follows RTL direction, and the selected value participates in native form submission.

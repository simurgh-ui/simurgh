## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add hover-card
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  HoverCard,
  HoverCardTrigger,
  HoverCardContent,
} from '@simurgh-ui/react/hover-card';
import '@simurgh-ui/styles/hover-card.css';
```

### Vue

```ts
import {
  HoverCard,
  HoverCardTrigger,
  HoverCardContent,
} from '@simurgh-ui/vue/hover-card';
import '@simurgh-ui/styles/hover-card.css';
```

### Angular

```ts
import { HoverCardComponent } from '@simurgh-ui/angular/hover-card';
import '@simurgh-ui/styles/hover-card.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.

## Purpose

Hover Card reveals a compact, labelled preview without requiring activation. Its trigger works with pointer hover and keyboard focus, and the card uses collision-aware positioning.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## State model

Keep hover-card content concise and nonessential. Use Dialog when the content requires a decision, form interaction, or modal focus management.

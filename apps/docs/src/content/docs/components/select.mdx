## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add select
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Select } from '@simurgh-ui/react/select';
import '@simurgh-ui/styles/select.css';
```

### Vue

```ts
import { Select } from '@simurgh-ui/vue/select';
import '@simurgh-ui/styles/select.css';
```

### Angular

```ts
import {
  SelectComponent,
  SelectOption,
} from '@simurgh-ui/angular/select';
import '@simurgh-ui/styles/select.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Select owns combobox/listbox state, disabled options, selection events, and a hidden native form value. Supply a visible placeholder that also names the trigger.

## State model

`name`, `value`, `required`, and `disabled` mirror native form concepts. Third-party form adapters are intentionally outside v1.

title: Sidebar

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Sidebar coordinates a native disclosure button with a complementary navigation region. Closing it uses the native `hidden` state, removing its links from keyboard and assistive-technology navigation.

<ComponentPreview title="Sidebar">
  <div style="display:flex;gap:1rem;align-items:flex-start;min-height:14rem">
    <button
      type="button"
      data-slot="sidebar-trigger"
      aria-controls="sidebar-preview"
      aria-expanded="true"
    >
      Toggle navigation
    </button>
    <aside
      id="sidebar-preview"
      data-slot="sidebar"
      data-side="start"
      data-state="open"
      aria-label="Workspace navigation"
    >
      <div data-slot="sidebar-header">
        <strong>Simurgh</strong>
      </div>
      <div data-slot="sidebar-content">
        <div data-slot="sidebar-group">
          <ul data-slot="sidebar-menu">
            <li>
              <a href="#projects">Projects</a>
            </li>
            <li>
              <a href="#settings">Settings</a>
            </li>
          </ul>
        </div>
      </div>
    </aside>
  </div>
</ComponentPreview>

<Tabs>
<TabItem label="React">
```tsx
<SidebarProvider defaultOpen onOpenChange={setSidebarOpen}>
  <SidebarTrigger>Toggle navigation</SidebarTrigger>
  <Sidebar aria-label="Workspace navigation">
    <SidebarHeader>Simurgh</SidebarHeader>
    <SidebarContent>
      <SidebarGroup>
        <SidebarMenu><li><a href="/projects">Projects</a></li></SidebarMenu>
      </SidebarGroup>
    </SidebarContent>
  </Sidebar>
</SidebarProvider>
```
</TabItem>
<TabItem label="Vue">
```vue
<SidebarProvider v-model:open="sidebarOpen">
  <SidebarTrigger>Toggle navigation</SidebarTrigger>
  <Sidebar aria-label="Workspace navigation">
    <SidebarHeader>Simurgh</SidebarHeader>
    <SidebarContent>
      <SidebarGroup>
        <SidebarMenu><li><a href="/projects">Projects</a></li></SidebarMenu>
      </SidebarGroup>
    </SidebarContent>
  </Sidebar>
</SidebarProvider>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-sidebar-provider [(open)]="sidebarOpen">
  <button simurghSidebarTrigger>Toggle navigation</button>
  <aside simurghSidebar aria-label="Workspace navigation">
    <div simurghSidebarHeader>Simurgh</div>
    <div simurghSidebarContent>
      <div simurghSidebarGroup>
        <ul simurghSidebarMenu><li><a href="/projects">Projects</a></li></ul>
      </div>
    </div>
  </aside>
</simurgh-sidebar-provider>
```
</TabItem>
</Tabs>

Give every sidebar a concise `aria-label`, keep the trigger visible outside the sidebar, and use `side="end"` when navigation belongs on the logical end edge. Logical CSS properties automatically mirror start and end placement in RTL documents.

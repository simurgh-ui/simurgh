import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Badge is a neutral inline label by default. Tone is exposed through `data-tone` for recipes, while optional status mode announces dynamic updates politely.

  </TabItem>

    ```vue
    <Badge tone="success">Published</Badge>
    ```
  </TabItem>
  <TabItem label="Angular">
    ```html
    <simurgh-badge tone="success">Published</simurgh-badge>
    ```
  </TabItem>
</Tabs>

Enable `status` only when badge text changes dynamically and should be announced.

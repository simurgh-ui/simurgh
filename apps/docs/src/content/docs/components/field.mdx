## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add field
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Field,
  FieldLegend,
  FieldDescription,
  FieldError,
} from '@simurgh-ui/react/field';
import '@simurgh-ui/styles/field.css';
```

### Vue

```ts
import {
  Field,
  FieldLegend,
  FieldDescription,
  FieldError,
} from '@simurgh-ui/vue/field';
import '@simurgh-ui/styles/field.css';
```

### Angular

```ts
import {
  FieldComponent,
  FieldLegendComponent,
  FieldDescriptionComponent,
  FieldErrorComponent,
} from '@simurgh-ui/angular/field';
import '@simurgh-ui/styles/field.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Field preserves native `fieldset` and `legend` behavior while providing consistent anatomy for help and error messages.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## State model

Connect descriptions and errors to controls with `aria-describedby`. Render FieldError only when a useful validation message exists.

## API surface

- React exports: `Field`, `FieldLegend`, `FieldDescription`, `FieldError`
- Vue exports: `Field`, `FieldLegend`, `FieldDescription`, `FieldError`
- Angular exports: `FieldComponent`, `FieldLegendComponent`, `FieldDescriptionComponent`, `FieldErrorComponent`

Import these public symbols from the component subpath shown in Installation. Framework-specific
props, events, slots, directives, methods, defaults, and native-attribute behavior belong in the API
tables on this page; use the linked source only to verify the current implementation.

---
title: Accordion
description: Single or multiple collapsible, labelled regions.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Each item combines a heading trigger and a labelled region. Single mode closes the previous item; multiple mode permits independent expansion.

## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add sheet
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetTitle,
  SheetDescription,
  SheetClose,
  SheetSide,
} from '@simurgh-ui/react/sheet';
import '@simurgh-ui/styles/sheet.css';
```

### Vue

```ts
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetTitle,
  SheetDescription,
  SheetClose,
  SheetSide,
} from '@simurgh-ui/vue/sheet';
import '@simurgh-ui/styles/sheet.css';
```

### Angular

```ts
import {
  SheetComponent,
  SheetSide,
} from '@simurgh-ui/angular/sheet';
import '@simurgh-ui/styles/sheet.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.

## Purpose

Sheet presents modal content from a logical edge of the viewport. It shares Dialog's accessible naming, focus containment, Escape dismissal, overlay behavior, and trigger-focus restoration.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## State model

Choose `left` or `right` for narrow task panels and `top` or `bottom` for short horizontal workflows. Logical inline positioning automatically follows document direction.

## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add popover
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Popover,
  PopoverTrigger,
  PopoverContent,
} from '@simurgh-ui/react/popover';
import '@simurgh-ui/styles/popover.css';
```

### Vue

```ts
import {
  Popover,
  PopoverTrigger,
  PopoverContent,
} from '@simurgh-ui/vue/popover';
import '@simurgh-ui/styles/popover.css';
```

### Angular

```ts
import { PopoverComponent } from '@simurgh-ui/angular/popover';
import '@simurgh-ui/styles/popover.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Popover uses Floating UI for offset, flip, shift, and automatic repositioning. Outside interaction and Escape dismiss it without trapping focus.

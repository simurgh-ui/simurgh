## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add drawer
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Drawer,
  DrawerTrigger,
  DrawerContent,
  DrawerTitle,
  DrawerDescription,
  DrawerClose,
} from '@simurgh-ui/react/drawer';
import '@simurgh-ui/styles/drawer.css';
```

### Vue

```ts
import {
  Drawer,
  DrawerTrigger,
  DrawerContent,
  DrawerTitle,
  DrawerDescription,
  DrawerClose,
} from '@simurgh-ui/vue/drawer';
import '@simurgh-ui/styles/drawer.css';
```

### Angular

```ts
import { DrawerComponent } from '@simurgh-ui/angular/drawer';
import '@simurgh-ui/styles/drawer.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

Drawer presents focused tasks from the bottom edge while retaining the library's modal dialog contract: accessible naming, focus containment, Escape and overlay dismissal, and trigger-focus restoration. Use the optional top side for interfaces anchored to the upper viewport edge.

Prefer Drawer for compact, touch-friendly tasks that fit within a partial viewport. Use Dialog for centered decisions and Sheet for full-height side panels. Drawer does not impose gesture handling, so applications can add drag behavior without changing its accessibility contract.

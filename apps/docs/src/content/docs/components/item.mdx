## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add item
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  ItemGroup,
  Item,
  ItemMedia,
  ItemContent,
  ItemTitle,

  ItemActions,
} from '@simurgh-ui/react/item';
import '@simurgh-ui/styles/item.css';
```

## Purpose

Item structures repeated rows such as files, settings, notifications, and search results. Item Group and Item provide native list/listitem roles while the remaining parts keep media, text, and actions consistently aligned.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## Basic usage

## State model

Give the group an accessible name when multiple lists occur on the same page. Media is decorative by default; set `decorative` to false when its accessible content adds information not repeated by the title or description.

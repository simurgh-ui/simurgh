## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add rating
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Rating,
  RatingProps,
} from '@simurgh-ui/react/rating';
import '@simurgh-ui/styles/rating.css';
```

### Vue

```ts
import { Rating } from '@simurgh-ui/vue/rating';
import '@simurgh-ui/styles/rating.css';
```

### Angular

```ts
import { RatingComponent } from '@simurgh-ui/angular/rating';
import '@simurgh-ui/styles/rating.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.

## Purpose

Rating collects a score with native radio semantics. It supports keyboard navigation, form submission, disabled and required states, controlled values, and localized item labels without adding a runtime dependency.

## State model

Set `max` to change the scale, up to 100 items. Provide `getLabel` in React or Vue when labels such as “Excellent” should replace the default “4 of 5” wording. Angular exposes the same default item labels and announces the group through `aria-label`.

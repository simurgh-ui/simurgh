Rating collects a score with native radio semantics. It supports keyboard navigation, form submission, disabled and required states, controlled values, and localized item labels without adding a runtime dependency.

<Tabs>
<TabItem label="React">
```tsx
<Rating aria-label="Product rating" name="rating" defaultValue={3} onValueChange={setRating} />
```
</TabItem>
<TabItem label="Vue">
```vue
<Rating v-model="rating" aria-label="Product rating" name="rating" />
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-rating aria-label="Product rating" name="rating" [(value)]="rating" />
```
</TabItem>
</Tabs>

Set `max` to change the scale, up to 100 items. Provide `getLabel` in React or Vue when labels such as “Excellent” should replace the default “4 of 5” wording. Angular exposes the same default item labels and announces the group through `aria-label`.

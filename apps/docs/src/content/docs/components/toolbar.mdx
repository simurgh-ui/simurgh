import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Toolbar groups related controls and moves focus with logical arrow keys while skipping disabled items.

<ComponentPreview title="Toolbar">
  <div
    role="toolbar"
    aria-label="Text formatting"
    aria-orientation="horizontal"
    data-slot="toolbar"
  >
    <button data-toolbar-item data-slot="toolbar-button">
      Bold
    </button>
    <button data-toolbar-item data-slot="toolbar-button">
      Italic
    </button>
    <button data-toolbar-item data-slot="toolbar-button">
      Link
    </button>
  </div>
</ComponentPreview>

Set `orientation="vertical"` for vertical command groups. Direction-aware horizontal navigation reverses appropriately in RTL layouts.

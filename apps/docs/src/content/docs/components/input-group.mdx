## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add input-group
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupText,
} from '@simurgh-ui/react/input-group';
import '@simurgh-ui/styles/input-group.css';
```

### Vue

```ts
import {
  InputGroup,
  InputGroupAddon,
  InputGroupText,
} from '@simurgh-ui/vue/input-group';
import '@simurgh-ui/styles/input-group.css';
```

### Angular

```ts
import {
  InputGroupComponent,
  InputGroupAddonComponent,
  InputGroupTextComponent,
} from '@simurgh-ui/angular/input-group';
import '@simurgh-ui/styles/input-group.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.

## Purpose

Input Group keeps a form control and its supporting adornments visually connected. Addons can appear on either inline edge or span the block start or end of the group.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## State model

Keep the actual input label visible or provide an equivalent accessible name. Set `decorative` only when the addon repeats visual context that should not be announced; otherwise its text remains available to assistive technology.

## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add input-group
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupText,
} from '@simurgh-ui/react/input-group';
import '@simurgh-ui/styles/input-group.css';
```

### Vue

```ts
import {
  InputGroup,
  InputGroupAddon,
  InputGroupText,
} from '@simurgh-ui/vue/input-group';
import '@simurgh-ui/styles/input-group.css';
```

### Angular

```ts
import {
  InputGroupComponent,
  InputGroupAddonComponent,
  InputGroupTextComponent,
} from '@simurgh-ui/angular/input-group';
import '@simurgh-ui/styles/input-group.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
<!-- component-installation:end -->

Input Group keeps a form control and its supporting adornments visually connected. Addons can appear on either inline edge or span the block start or end of the group.

<ComponentPreview title="Input Group">
  <label id="website-preview-label" for="website-preview">
    Website
  </label>
  <div
    role="group"
    aria-labelledby="website-preview-label"
    data-slot="input-group"
  >
    <div
      data-slot="input-group-addon"
      data-align="inline-start"
      aria-hidden="true"
    >
      <span data-slot="input-group-text">https://</span>
    </div>
    <input id="website-preview" name="website" placeholder="example.com" />
  </div>
</ComponentPreview>

<Tabs>
<TabItem label="React">
```tsx
<Label id="website-label" htmlFor="website">Website</Label>
<InputGroup aria-labelledby="website-label">
  <InputGroupAddon decorative>
    <InputGroupText>https://</InputGroupText>
  </InputGroupAddon>
  <Input id="website" name="website" placeholder="example.com" />
</InputGroup>
```
</TabItem>
<TabItem label="Vue">
```vue
<Label id="website-label" for="website">Website</Label>
<InputGroup aria-labelledby="website-label">
  <InputGroupAddon decorative>
    <InputGroupText>https://</InputGroupText>
  </InputGroupAddon>
  <Input id="website" name="website" v-model="website" placeholder="example.com" />
</InputGroup>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-label id="website-label" for="website">Website</simurgh-label>
<simurgh-input-group aria-labelledby="website-label">
  <simurgh-input-group-addon [decorative]="true">
    <simurgh-input-group-text>https://</simurgh-input-group-text>
  </simurgh-input-group-addon>
  <simurgh-input id="website" name="website" [value]="website" (valueChange)="website = $event" />
</simurgh-input-group>
```
</TabItem>
</Tabs>

Keep the actual input label visible or provide an equivalent accessible name. Set `decorative` only when the addon repeats visual context that should not be announced; otherwise its text remains available to assistive technology.

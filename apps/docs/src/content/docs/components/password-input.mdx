
## Purpose

Password Input preserves one native form control while switching its visual type between `password` and `text`. The toggle names its current action, exposes pressed state, and references the controlled input.

## State model

Prefer a visible external label when layout permits. Use `autocomplete="current-password"` for sign-in and `autocomplete="new-password"` for account creation. Revealing changes only presentation; it does not copy, clear, or replace the input value.

An inherited-attributes entry means the component accepts the complete named React native interface,

### `PasswordInput`

Inherited attributes: `InputHTMLAttributes<HTMLInputElement> & RefAttributes<HTMLInputElement>`.

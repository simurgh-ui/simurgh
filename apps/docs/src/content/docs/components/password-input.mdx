title: Password Input

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Password Input preserves one native form control while switching its visual type between `password` and `text`. The toggle names its current action, exposes pressed state, and references the controlled input.

<ComponentPreview title="Password Input">
  <label for="password-preview" style="display:block;margin-bottom:.5rem">
    Account password
  </label>
  <div data-slot="password-input" style="max-width:24rem">
    <input
      id="password-preview"
      type="password"
      value="correct horse battery staple"
      autocomplete="current-password"
      data-slot="password-input-control"
    />
    <button
      type="button"
      data-slot="password-input-toggle"
      aria-controls="password-preview"
      aria-label="Show password"
      aria-pressed="false"
    >
      Show
    </button>
  </div>
</ComponentPreview>

<Tabs>
<TabItem label="React">
```tsx
<PasswordInput
  aria-label="Account password"
  name="password"
  autoComplete="current-password"
  value={password}
  onChange={(event) => setPassword(event.target.value)}
/>
```
</TabItem>
<TabItem label="Vue">
```vue
<PasswordInput
  v-model="password"
  aria-label="Account password"
  name="password"
  autocomplete="current-password"
/>
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-password-input
  [(value)]="password"
  aria-label="Account password"
  name="password"
  autocomplete="current-password"
/>
```
</TabItem>
</Tabs>

Prefer a visible external label when layout permits. Use `autocomplete="current-password"` for sign-in and `autocomplete="new-password"` for account creation. Revealing changes only presentation; it does not copy, clear, or replace the input value.

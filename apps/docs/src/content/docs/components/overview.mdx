title: Component overview
description: Fifty-six accessible primitives with framework-native APIs.
---

| Primitive       | Primary accessibility contract                      | Native form value |
| --------------- | --------------------------------------------------- | ----------------- |
| Dialog          | Modal semantics, focus containment and restoration  | —                 |
| Popover         | Dismissible, collision-aware anchored content       | —                 |
| Tooltip         | Hover and focus description                         | —                 |
| Dropdown Menu   | Menu roles, disabled items and selection            | —                 |
| Select          | Combobox/listbox semantics and option selection     | Yes               |
| Combobox        | Editable filtering with active-descendant focus     | Yes               |
| Command         | Searchable actions with active-descendant focus     | Optional          |
| Calendar        | Labelled date grid with roving keyboard focus       | Yes               |
| Date Picker     | Dismissible calendar popup with focus restoration   | Yes               |
| Tabs            | Roving focus, directional navigation and panels     | —                 |
| Accordion       | Disclosure state and labelled regions               | —                 |
| Checkbox        | Checkbox role, checked and disabled states          | Yes               |
| Separator       | Semantic or decorative content division             | —                 |
| Progress        | Determinate or indeterminate task status            | —                 |
| Label           | Native accessible naming and control association    | —                 |
| Toggle          | Native pressed state and keyboard activation        | —                 |
| Visually Hidden | Screen-reader text without visual layout impact     | —                 |
| Avatar          | Image loading with deterministic text fallback      | —                 |
| Alert           | Polite or assertive live-region feedback            | —                 |
| Aspect Ratio    | Stable media proportions with safe fallback         | —                 |
| Skeleton        | Decorative or named busy loading placeholder        | —                 |
| Spinner         | Named polite busy status for indeterminate work     | —                 |
| Button          | Native activation with disabled and busy states     | —                 |
| Button Group    | Named grouping and visual composition of actions    | No                |
| Input           | Native form value and validation semantics          | Yes               |
| Input Group     | Grouped input with contextual prefix or suffix      | Yes               |
| Input OTP       | Autofill-ready one-time code entry and validation   | Yes               |
| Empty           | Static zero-state content or optional polite status | No                |
| Item            | Native list structure with named row content        | No                |
| Textarea        | Native multiline form and validation semantics      | Yes               |
| Badge           | Neutral metadata or optional polite status          | —                 |
| Breadcrumb      | Named navigation landmark and current page          | —                 |
| Switch          | Switch role, checked and disabled states            | Yes               |
| Radio Group     | Roving focus and single-choice selection            | Yes               |
| Menubar         | Direction-aware roving focus for application menus  | No                |
| Hover Card      | Hover and focus disclosure of supplementary detail  | No                |
| Context Menu    | Pointer and keyboard access to contextual actions   | No                |
| Sheet           | Side-anchored modal with focus containment          | No                |
| Drawer          | Bottom-anchored modal with focus containment        | No                |
| Alert Dialog    | Interruptive confirmation with safe initial focus   | No                |
| Form            | Native validation with first-invalid focus          | Yes               |
| Native Select   | Platform-native option selection and validation     | Yes               |
| Toast           | Polite status announcements and dismissal           | —                 |

Every registry item has Angular, React, and Vue source. APIs share the same anatomy while preserving each framework’s conventions: inputs/outputs in Angular, props/callbacks in React, and props/emits with slots in Vue.

---
title: Label
description: A native label primitive for accessible form-control naming.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

Label renders a native HTML `<label>`. It provides reliable accessible naming and preserves browser behavior such as activating or focusing the associated control when the label is selected.

<Tabs>
  <TabItem label="React">
    ```tsx
    <Label htmlFor="email">Email address</Label>
    <input id="email" type="email" />
    ```
  </TabItem>
  <TabItem label="Vue">
    ```vue
    <Label for="email">Email address</Label>
    <input id="email" type="email" />
    ```
  </TabItem>
  <TabItem label="Angular">
    ```html
    <simurgh-label for="email">Email address</simurgh-label>
    <input id="email" type="email" />
    ```
  </TabItem>
</Tabs>

The primitive is deliberately headless and forwards native attributes. The `for`/`htmlFor` value must match the target control ID. Wrapping a control inside the label also uses normal browser semantics.

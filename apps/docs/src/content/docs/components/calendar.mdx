## Purpose

Calendar renders a labelled six-week date grid. It supports controlled or uncontrolled selection, month navigation, locale-aware labels, RTL arrows, constrained dates, and ISO `YYYY-MM-DD` form values.

## State model

Controlled state remains the application’s source of truth and must be updated from every change
event. Uncontrolled state reads its default only when the component mounts. Do not pass both forms of
the same state at once.

| Framework | Exact state contract and reset behavior |
| --- | --- |
| React | Controlled: `month` + `onMonthChange`. Uncontrolled: `defaultMonth`. Reset controlled state by assigning the initial value; reset uncontrolled state by changing a React `key`.<br />Controlled: `value` + `onValueChange`. Uncontrolled: `defaultValue`. Reset controlled state by assigning the initial value; reset uncontrolled state by changing a React `key`. |
| Vue | Controlled: `v-model` (`modelValue` + `update:modelValue`). Uncontrolled: `defaultValue`. Reset the model ref to its initial value; reset uncontrolled state with a changed Vue `:key`.<br />Controlled: `v-model:month` (`month` + `update:month`). Uncontrolled: `defaultMonth`. Reset the model ref to its initial value; reset uncontrolled state with a changed Vue `:key`. |
| Angular | Controlled two-way binding: `[(value)]` (`value` + `valueChange`). Angular exposes no separate default input; initialize and reset the bound class field explicitly.<br />Controlled two-way binding: `[(month)]` (`month` + `monthChange`). Angular exposes no separate default input; initialize and reset the bound class field explicitly. |

**React**

```tsx
const initialMonth = '';
const [month, setMonth] = useState(initialMonth);
const [resetKey, setResetKey] = useState(0);

<Calendar month={month} onMonthChange={setMonth}>…</Calendar>
<button onClick={() => setMonth(initialMonth)}>Reset controlled</button>
<Calendar key={resetKey} defaultMonth={initialMonth}>…</Calendar>
<button onClick={() => setResetKey((key) => key + 1)}>Reset uncontrolled</button>
```

**Vue**

```vue
<script setup lang="ts">
import { ref } from 'vue';
const initial = '';
const state = ref(initial);
const resetKey = ref(0);
</script>

<Calendar v-model="state">…</Calendar>
<button @click="state = initial">Reset controlled</button>
<Calendar :key="resetKey" :defaultValue="initial">…</Calendar>
<button @click="resetKey++">Reset uncontrolled</button>
```

**Angular**

```ts
initial = '';
value = this.initial;
reset() { this.value = this.initial; }
```

```html
<simurgh-calendar [(value)]="value">…</simurgh-calendar>
<button type="button" (click)="reset()">Reset</button>
```

Arrow keys move by day or week; Home and End move within the week; Page Up and Page Down move by month. Use `min`, `max`, or `disabledDates` for unavailable dates. The component uses locale-aware spoken labels while keeping emitted and submitted values stable ISO dates.

### Keyboard interactions

These keys describe behavior implemented by the adapters. Native Tab, Enter, and Space behavior still
applies to descendant links, buttons, and form controls unless the component overrides it.

| Concern / keys | Behavior |
| --- | --- |
| Focus entry and exit (Tab / Shift+Tab) | Tab enters the grid at the roving-tabindex day; Tab leaves the grid. |
| Navigation and activation | Arrow Up/Down moves one week; Home/End moves to week edges; Enter or Space selects. |
| Escape | Not handled; focus remains in the calendar. |
| RTL differences | Arrow Left/Right date movement reverses in RTL. |
| Typeahead | Not supported. |

The adapters target the same user-visible behavior and accessibility contract. Their public shapes

### Form integration

Use `name="appointmentDate"` to serialize the current value under the documented field name. The examples initialize the field, keep its
value application-owned, forward `disabled` and `required`, render an accessible error, and read
the browser submission payload. This component has no public `invalid` prop; announce validation errors next to the labeled control and use native validity where available.

#### React

```tsx
const initial = '2026-08-12';
const [value, setValue] = useState(initial);
const [errors, setErrors] = useState<Record<string, string>>({});

<form onSubmit={(event) => {
  event.preventDefault();
  const data = new FormData(event.currentTarget);
  // Submit data.get('appointmentDate').
}}>
  <Calendar name="appointmentDate" value={value} onValueChange={setValue}
    required disabled={isDisabled} />
  {errors.appointmentDate && <p role="alert">{errors.appointmentDate}</p>}
  <button type="submit">Submit</button>
</form>
```

#### Vue

```vue
<script setup lang="ts">
import { reactive, ref } from 'vue';
const initial = '2026-08-12';
const value = ref(initial);
const errors = reactive<Record<string, string>>({});
function submit(event: Event) {
  const data = new FormData(event.currentTarget as HTMLFormElement);
  // Submit data.get('appointmentDate').
}
</script>

<form @submit.prevent="submit">
  <Calendar v-model="value" name="appointmentDate" required :disabled="isDisabled"></Calendar>
  <p v-if="errors.appointmentDate" role="alert">{{ errors.appointmentDate }}</p>
  <button type="submit">Submit</button>
</form>
```

#### Angular

```ts
initial = '2026-08-12';
value = this.initial;
errors: Record<string, string> = {};
submit(form: HTMLFormElement) {
  const data = new FormData(form);
  // Submit data.get('appointmentDate').
}
```

```html
<form #form (submit)="submit(form); $event.preventDefault()">
  <simurgh-calendar [(value)]="value" name="appointmentDate" required [disabled]="isDisabled"></simurgh-calendar>
  <p *ngIf="errors.appointmentDate" role="alert">{{ errors.appointmentDate }}</p>
  <button type="submit">Submit</button>
</form>
```

For Angular reactive or template-driven forms, bridge the documented `value`/`valueChange` pair
to your form control. The component does not implement `ControlValueAccessor`; update disabled and
validation state from the Angular form explicitly.

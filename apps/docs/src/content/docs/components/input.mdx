## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add input
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Input } from '@simurgh-ui/react/input';
import '@simurgh-ui/styles/input.css';
```

### Vue

```ts
import { Input } from '@simurgh-ui/vue/input';
import '@simurgh-ui/styles/input.css';
```

### Angular

```ts
import { InputComponent } from '@simurgh-ui/angular/input';
import '@simurgh-ui/styles/input.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
<!-- component-installation:end -->

Input preserves native form submission, browser validation, input types, required and disabled states, while exposing explicit invalid semantics.

<Tabs>
<TabItem label="React">
```tsx
<Input name="email" type="email" required invalid={hasError} />
```
</TabItem>
<TabItem label="Vue">
```vue
<Input v-model="email" name="email" type="email" required :invalid="hasError" />
```
</TabItem>
<TabItem label="Angular">
```html
<simurgh-input [(value)]="email" name="email" type="email" [required]="true" [invalid]="hasError" />
```
</TabItem>
</Tabs>

Pair Input with Label and connect validation text using `aria-describedby`. The `invalid` option sets `aria-invalid`; it does not replace validation logic.

## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add disclosure
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Disclosure,
  DisclosureSummary,
  DisclosureContent,
} from '@simurgh-ui/react/disclosure';
import '@simurgh-ui/styles/disclosure.css';
```

### Vue

```ts
import {
  Disclosure,
  DisclosureSummary,
  DisclosureContent,
} from '@simurgh-ui/vue/disclosure';
import '@simurgh-ui/styles/disclosure.css';
```

### Angular

```ts
import {
  DisclosureComponent,
  DisclosureSummaryDirective,
  DisclosureContentDirective,
} from '@simurgh-ui/angular/disclosure';
import '@simurgh-ui/styles/disclosure.css';
```

## Purpose

Disclosure builds on native `<details>` and `<summary>`, preserving browser keyboard interaction, find-in-page behavior, and no-JavaScript fallback while exposing framework-native state events.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## Basic usage

## State model

Use Disclosure for independent expandable information. Use Accordion when several related sections need coordinated open state.

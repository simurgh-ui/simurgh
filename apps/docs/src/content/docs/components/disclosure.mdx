## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add disclosure
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Disclosure,
  DisclosureSummary,
  DisclosureContent,
} from '@simurgh-ui/react/disclosure';
import '@simurgh-ui/styles/disclosure.css';
```

### Vue

```ts
import {
  Disclosure,
  DisclosureSummary,
  DisclosureContent,
} from '@simurgh-ui/vue/disclosure';
import '@simurgh-ui/styles/disclosure.css';
```

### Angular

```ts
import {
  DisclosureComponent,
  DisclosureSummaryDirective,
  DisclosureContentDirective,
} from '@simurgh-ui/angular/disclosure';
import '@simurgh-ui/styles/disclosure.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
<!-- component-installation:end -->

Disclosure builds on native `<details>` and `<summary>`, preserving browser keyboard interaction, find-in-page behavior, and no-JavaScript fallback while exposing framework-native state events.

<ComponentPreview title="Disclosure">
  <details data-slot="disclosure">

    <div data-slot="disclosure-content">
      It remains interactive before hydration and follows the browser's
      accessibility model.
    </div>
  </details>
</ComponentPreview>

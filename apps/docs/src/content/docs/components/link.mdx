title: Link
description: Native anchor navigation with external and disabled states.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Link preserves native anchor behavior. The `external` option supplies a new browsing context and safe relationship defaults, while `disabled` removes navigation and keyboard focus.

<TabItem label="Angular">

```html
<simurgh-link href="/docs">Documentation</simurgh-link>
<simurgh-link href="https://example.com" [external]="true">External resource</simurgh-link>
```
</TabItem>
</Tabs>

Use Link for navigation and Button for actions. Disabled links intentionally omit `href`, expose `aria-disabled`, and leave the tab sequence.

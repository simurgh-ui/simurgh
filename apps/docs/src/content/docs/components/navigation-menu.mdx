## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add navigation-menu
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  NavigationMenu,
  NavigationMenuList,
  NavigationMenuItem,
  NavigationMenuLink,
} from '@simurgh-ui/react/navigation-menu';
import '@simurgh-ui/styles/navigation-menu.css';
```

### Vue

```ts
import {
  NavigationMenu,
  NavigationMenuList,
  NavigationMenuItem,
  NavigationMenuLink,
} from '@simurgh-ui/vue/navigation-menu';
import '@simurgh-ui/styles/navigation-menu.css';
```

### Angular

```ts
import {
  NavigationMenuComponent,
  NavigationMenuListDirective,
  NavigationMenuItemDirective,
  NavigationMenuLinkDirective,
} from '@simurgh-ui/angular/navigation-menu';
import '@simurgh-ui/styles/navigation-menu.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
<!-- component-installation:end -->

Navigation Menu composes a named navigation landmark, a native list, and standard anchors. Browser link behavior remains intact for keyboard users, assistive technology, context menus, and modified clicks.

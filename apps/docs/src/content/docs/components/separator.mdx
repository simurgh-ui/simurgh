## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add separator
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { Separator } from '@simurgh-ui/react/separator';
import '@simurgh-ui/styles/separator.css';
```

### Vue

```ts
import { Separator } from '@simurgh-ui/vue/separator';
import '@simurgh-ui/styles/separator.css';
```

### Angular

```ts
import { SeparatorComponent } from '@simurgh-ui/angular/separator';
import '@simurgh-ui/styles/separator.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
<!-- component-installation:end -->

Separator divides related sections visually and, by default, exposes the native `separator` role. Decorative mode removes it from the accessibility tree when the division is purely visual.

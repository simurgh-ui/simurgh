import { Tabs, TabItem } from '@astrojs/starlight/components';
import ComponentPreview from '../../../components/ComponentPreview.astro';

Separator divides related sections visually and, by default, exposes the native `separator` role. Decorative mode removes it from the accessibility tree when the division is purely visual.

Use `vertical` orientation only when the rendered divider is visually vertical. Set `decorative` when adjacent structure or spacing already conveys the grouping.

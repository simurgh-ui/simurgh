## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add scroll-area
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import { ScrollArea } from '@simurgh-ui/react/scroll-area';
import '@simurgh-ui/styles/scroll-area.css';
```

### Vue

```ts
import { ScrollArea } from '@simurgh-ui/vue/scroll-area';
import '@simurgh-ui/styles/scroll-area.css';
```

### Angular

```ts
import { ScrollAreaComponent } from '@simurgh-ui/angular/scroll-area';
import '@simurgh-ui/styles/scroll-area.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Scroll Area keeps browser-native scrolling while providing focus treatment, logical overflow modes, and restrained scrollbar styling.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;

## State model

Provide `label` when the area is an important standalone region. Native overflow preserves wheel, touch, keyboard, assistive-technology, and RTL scrolling behavior.

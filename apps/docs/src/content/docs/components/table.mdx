## Installation

Copy editable source into an initialized application:

```sh
pnpm dlx @simurgh-ui/cli add table
```

For package consumption, import from the component subpath and load its optional recipe CSS:

### React

```tsx
import {
  Table,
  TableHeader,
  TableBody,
  TableFooter,
  TableRow,
  TableHead,
  TableCell,
  TableCaption,
} from '@simurgh-ui/react/table';
import '@simurgh-ui/styles/table.css';
```

### Vue

```ts
import {
  Table,
  TableHeader,
  TableBody,
  TableFooter,
  TableRow,
  TableHead,
  TableCell,
  TableCaption,
} from '@simurgh-ui/vue/table';
import '@simurgh-ui/styles/table.css';
```

### Angular

```ts
import {
  TableDirective,
  TableHeaderDirective,
  TableBodyDirective,
  TableFooterDirective,
  TableRowDirective,
  TableHeadDirective,
  TableCellDirective,
  TableCaptionDirective,
} from '@simurgh-ui/angular/table';
import '@simurgh-ui/styles/table.css';
```

Omit the component stylesheet for fully headless styling. CLI-copied components use the local path
written to `simurgh.json` and the copied application styles instead of these package imports.
{/* component-installation:end */}

## Purpose

Table keeps native caption, section, row, header, and cell semantics while adding stable styling hooks.

## Anatomy

The public component parts are listed in API surface below. Use only the parts needed by the example;
compound components depend on their documented parent/child nesting.

## State model

Use a caption when the table needs an accessible name. Angular uses attribute directives to preserve valid native table structure.

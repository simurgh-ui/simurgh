Simurgh UI combines shared accessibility behavior with framework-native composition. Its optional recipes use a palette grounded in Iranian firuzeh tile, Persian blue, cobalt glaze, ochre brick, saffron, and pomegranate.

The CLI copies editable source into your application. There is no opaque component runtime and Tailwind is optional.

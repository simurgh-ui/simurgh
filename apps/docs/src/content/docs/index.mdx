Simurgh UI combines shared accessibility behavior with framework-native composition. Its optional recipes use a palette grounded in Iranian firuzeh tile, Persian blue, cobalt glaze, ochre brick, saffron, and pomegranate.

Use Simurgh in either of two ways: copy editable framework-native source into your application with
the CLI, or install the published Angular, React, or Vue adapter as a normal dependency. Copied
components use local import paths and are yours to maintain; package components use
`@simurgh-ui/*` imports and follow package upgrades. The optional CSS recipes work with either
model, and Tailwind is not required.

See [Installation](/guides/installation/) for complete framework quick starts and guidance on
choosing an installation model.

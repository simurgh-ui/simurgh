# Security policy

## Supported versions

Simurgh UI is pre-release. Security fixes are applied to the latest published version of each
package; older `0.x` versions are not guaranteed to receive backports.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting for the `simurgh-ui/simurgh` repository. Include the affected package and version, impact,
reproduction steps or a proof of concept, and any known mitigations.

Maintainers should acknowledge a report within seven days, keep the reporter informed while it is
investigated, and coordinate disclosure after a fix or mitigation is available. Reports made in
good faith will not be penalized.

Accessibility defects and ordinary correctness bugs that do not create a security boundary failure
should use the public issue tracker.
